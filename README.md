# 高二（2）班：最后一节课

## v3.2「七日课表」

单文件校园恐怖潜行游戏。新开局采用**上午5节、下午4节、两节晚自习**的随机课表；07:20 到校，21:40 放学。加入连续七日挑战、教师行为差异与后排站立状态。当前 **24 个结局、87 项成就**。

所有人物、学校与情节均为虚构。角色姓名和本版行为详见 **[人物档案.md](人物档案.md)**。

## 运行与全屏

打开同目录的 `index.html`。HTML、CSS、JavaScript、国际象棋规则与音效代码全部包含其中，无后端、外部图片、音频、运行框架或 CDN。其他文档和测试文件不影响运行。

右上角 **“全屏”** 或 **Alt + Enter** 切换全屏；浏览器拒绝请求时游戏会提示。退出全屏、离开页面或失焦会暂停；回到页面后手动继续。暂停和读档准备不会消耗课堂、棋局或挑战时间。

升级前建议从旧版本的“存档”菜单导出 JSON，再在新版导入。重要进度应保留单独备份；不要把浏览器本地记录当作云存档。

## 开局模式

**开始新的一天／快速模式：** 单日随机课表。标准与快速只决定活动时长，不替代六档难度。

**一周挑战：** 主菜单新增独立入口，可选标准或快速课时。连续挑战星期一至星期日七个游戏日；这是虚构校园的挑战规则，不对应现实学校作息。

每天需要完成当天课表并达成一个**成功离校结局**，才进入日结页。选择“继续下一天”从次日07:20开始；也可以保存退出。坏结局、被抓和留校循环不会计为成功的一天，但可以从检查点重试。

七天课表在开局时一并确定。读档、暂停、查看课表、换窗口都不重新抽签。难度与课时速度整周固定。资源、普通课堂统计、同学帮助与纪律按天重置；**国际象棋局面与战绩跨天保留**。全局已解锁成就、结局和日期一直保留。

神级仍是180秒闭环的必败挑战，不存在借七日结局绕过神级封锁的出口。

### 条件反射与快速反应仍然分开

**条件反射：** 恢复的 v2.2 静止规则不变。普通难度准备1.4秒、连续静止1.4秒，一次明显误操作容错。不要点击数字。

**快速反应：** 简单2空格、普通3空格；困难、地狱、极限、神级分别为3、4、5、6个数字。统一0.4秒准备，基础操作时间仍为2.8／2.6／3.0／3.3／3.6／3.9秒。数字档允许一次误按扣时，不清空正确步骤。

触屏点击目标大数字；键盘按目标所在按钮的左起位置键。例如上排 `3 1 5 2 4`，下方提示 `4 2 5 1 3`，键盘输入 `5 4 3 2 1`，触屏点击大数字 `4 2 5 1 3`。

## 保留的玩法

国际象棋仍为8×8，支持合法着法、将军、将死、易位、吃过路兵、升变与和棋；使用轻量AI，不是专业棋力引擎。三次重复与五十回合采用自动判和的游戏化简化。课上棋局不暂停巡视，空格可保留局面收棋。

纸条、睡觉、讲话、办公室、午晚餐与搜包、体育、两种家长监督、后门登记与恐怖强化继续使用。恐怖强化默认关闭，不额外修改反应限时或突然提高主音量。

本次主要平衡调整是按教师区别暴露类型，不把“不走动”做成免检；全局没有再压缩反应时间。新课表更长，作业基础效率调整为标准0.25%／秒、快速0.50%／秒，再乘难度收益倍率；讲授听课的无聊增长略降。

## 存档与旧版迁移

每5秒及关键操作尝试保存；中断页面时保存并暂停。自动记录和安全检查点分开，失败不覆盖之前的重试点。支持手动保存、JSON导入／导出、从最近检查点重新出发。

新存档包含七天课表、日序、已完成的每日结果、习题课标记、讲话／低头暴露、站立状态和国际象棋局面。日结本身也可以读档，不会再算一次已完成的天数。

**v3.1及更早的中途记录保留其旧课表，不在半途重新排课。** 教师新行为立即适用；旧版物理移动位置会归回讲台。已有棋局、当前时间、属性和档案继续保留。体验新15阶段课表或七日模式需要新开局，不把旧档缺失的阶段补成“已完成”。

旧的12／20／23结局收集范围不变，七日新结局不会冒充某个旧结局。
