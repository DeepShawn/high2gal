# 高二（2）班：最后一节课
## v3.7 · 光与回执

单文件校园潜行／恐怖／剧情游戏。运行只需 `index.html`，HTML、CSS、JavaScript、场景、国际象棋和程序音效均内置，没有CDN、外部图片、音频文件或后端。人物均使用化名，经历、台词和校规事件均为虚构。班长彭望梓保留猫耳及蝶结发卡，没有猫尾。

**本版：38条结局档案、144项成就、196道可用题目条目。** 其中161道普通题（语文5、化学30、生物30、物理30、英语30、数学36），另有35道高中数学56选一；题数包含参数不同的计算变式，并不表示196个互不相同的知识点。本次保留原32条结局、124项成就条件，新增6条结局、20项成就。

## 运行与全屏

解压后用浏览器打开 `index.html`；用文本编辑器打开同一文件可以查看完整代码。标准／快速是课时长度，简单／普通／困难／地狱／极限／神级是难度，两者独立。主菜单可选单日学校、七日挑战或归家。

**全屏：右上角按钮或 Alt + Enter。暂停：Esc。** 全屏被浏览器拒绝时有文字提示。教程、考试与卧室也有独立系统按钮。手机横屏更适合完整教室布局。

## 先读新手教程

主菜单和游戏顶部都有“教程”。共有13章：目标、课桌与数值、快速反应、静止条件反射、考试、校园事务、魔方与国际象棋、同学与班长、归家、道具与后门、真实模式、知识／影像／语音、存档。

6类独立练习沿用原版：课桌操作、快速反应、静止、考试、魔方、归家。新增3章为机制讲解，**没有将正式周目的收缴、镜片或答题结果作为教程练习统计**。打开教程暂停正式状态，关闭回到原暂停／恢复流程，练习不加怀疑、不算作弊、不发正式成就。

## 反光镜是实际道具

简单、普通新开局自带；困难、地狱、极限、神级新开局没有。

在到校、课间、体育、午休等允许自由活动的时段，点击道具栏“找体委 · 反光镜”，向王梓锐答一道高中物理题。答对立即取得，答错不算课堂成绩，20秒后可以再试。体委睡着、正在考试、早晨收作业前的专属工作阶段不可交易。有镜后按钮退出寻找状态，取得方式与持有状态会保存。

没有镜子时，点击“回头看后门”或观察面板里的“回头 · 后门”。动作先收好当前物品，转身1.15秒后获得4秒直接视野，随后转回课本；时间和巡视继续。尚未回头时不会直接显示后门中的人影。门把手、声音与文字警告仍存在，镜子不是唯一预警来源。

镜片与本周收缴记录跨日保留，主动识别次数按日重新统计。

## 真实模式（默认关闭）

**设置 → 真实模式。只决定新开周目的规则，不中途改写当前难度。**

课堂正式快速反应失败时，怀疑直接变为100%，弹出老师要求交出物品的确认。手机、魔方、棋盘、纸条／情书纸、无刃塑料玩具、其他作业本可以被收缴。交出后按钮隐藏，相应快捷键和操作入口也被禁用。若当时只是讲话或睡觉、没有手持物品，记一次处分，但不删除这些基本行为或听课／观察／答题功能。原教学演示与新手教程不适用正式收缴处罚。

**“永久”指当前周目：整周、次日、刷新、检查点回读和同一记录的JSON导入都不会返还；新开周目重置本轮收缴。** 收缴清单作为同一runId下的不可回退记录保存在本地档案中，导出时随备份一起带走。人为编辑JSON、清除本地所有记录不属于防作弊保护范围。

一件被收走后仍可继续上课并成功离校；同一周目收缴3种不同物品会进入《收缴清单》。处理结束后的怀疑降到60，避免下一帧再次因同一100%重复处分；并非把快反失败仅仅改为增加固定分数。

原模式仍使用一般课堂+36、数学+48的基础失败惩罚。生物“条件反射”还是松手静止，不受快反收缴逻辑替换。

归家沿用之前已明确的**家中备用手机**，不是取回校园收缴手机；校园按钮不会因为回家恢复。夜间多步隐藏与被发现规则保持原样。

## 后门、校长与办公室

普通难度的周期尝试间隔约32秒；基础12%，手机22%，高怀疑27%，数学32%，第二节晚自习10%，按优先级择一而非相加，随后应用难度倍率。真实巡视结束至少再等28秒。全局危险提高但不叠加到正式笔试：笔试期间仍坐姿监考，保留原考试独立注意机制。

真实后门先给1.8秒预警，再累计违规暴露；手机约1.15秒持续暴露、讲话1.05秒、下棋1.7秒才登记。普通模式观察期间手机的基础怀疑增长为16／秒，下棋3.5／秒，另应用已有倍率。折返仍存在，不要看到影子变淡就重开手机。

郭梓晁巡视时有可能准备拍照片或录像，举机时给出提示，未确认前收好可以阻止该次取证。登记后预约下课办公室：**先训话／说明，再逐条看影像**。照片为定格，录像为3秒程序绘制的多帧示意；录像看完才能确认，暂停和存档保留播放位置。所有影像和家长通知仅为游戏内部数据，不访问摄像头、相册或真实联系人。

程今容：正校长，保留用户已提供化名。文字速度更慢，有长停顿和“呼……”台词；语文课后段可登场，也可能巡视后门。徐亥：校长，保留已提供化名，会检查桌角、窗边和物品摆放，在第一节晚自习追加实际卫生任务，也可能出现在后门。

## 题库与56选一提示

非语文普通题全部改为高中学科知识：数列、导数、概率、向量、圆锥曲线；电学、力学、波动与近代物理；化学平衡、电化学、物质的量与有机基础；遗传、代谢、调节和生态；高中语法及篇章推断等。题目不以“打开手机”“按空格”等操作说明冒充物理／生物／英语题。

普通题按每科独立洗牌题堆抽取，题堆耗尽后再洗牌；队列保存在记录里。每节六科的额外提问机会由3增至4，仍排队执行，不在同一画面叠两道题。长题适当补时间，中文学科题至少10秒、英语至少11秒，并按题干长度补至多3秒。旧教师事件与连堂三题测试保留。

56选一专用35题，只有这些题显示学习发光。强度公式：

`听课比例 × min(数学听课秒数 / 30, 1)`

比例只统计当天数学课堂有效自由行动时间；暂停、剧情、题目、其他学科和教程不累计。比如数学听课15／30秒，初始强度25%；30／30秒为100%；0秒无光。光在3.2秒内渐弱，四选一绝不提示正确按钮。旧档不凭空补造无法证明的数学听课记录。

尹沙沙新语录：**“省水省电省实验。”** 已加入英语开场，不只是写进人物档案。

## 对话语音（默认关闭）

设置 → 对话语音播报，附试听按钮。使用浏览器SpeechSynthesis；只选择本地中文语音，未找到时提示并保留文字，不阻塞手动继续。程今容使用约0.52倍语速并分句停顿，不模仿真人声音。暂停、切出页面、跳到下一句或关闭功能会停止旧播报，避免叠音；主音量为0时停止正在播放的语音。

系统是否安装可用中文语音、浏览器是否允许播放决定能否真正发声。本版测试包含API路径与缺失回退，但不把模拟语音队列当作真人音质验收。无需麦克风，游戏不申请录音或摄像头权限。

旧版先导出JSON，新版通过“存档 → 导入备份”恢复。v3.6考试中途记录已使用旧版实际生成的快照验证，题目／选项／时间保留；旧周目真实模式默认为关闭，镜片按起始难度初始化。旧档不凭空补发取得镜片、校长或影像成就。已完成的日期不强制重玩。
