# 高二（2）班：最后一节课
## v3.8 · 题目分级与计时

单HTML校园恐怖潜行／对话游戏。本版以v3.7.1为基础，重点修改所有题目的分级和作答预算，不重写题目、不改变正确答案、不新增结局和成就。目前保留38条结局档案、144项成就。

## 运行

用桌面浏览器打开 `index.html` 即可。HTML、CSS、JavaScript、程序绘制场景和音效全部包含在此文件内，游戏本体没有后端、CDN或外部运行依赖。源码与可运行文件是同一个文件。

点击右上角“全屏”或按 `Alt + Enter` 切换；浏览器不支持或拒绝时会显示提示。手机浏览器支持情况需以设备实际表现为准。

本版测试代码需要另行安装Python与Playwright以及Chromium，这些只是开发测试依赖，玩游戏不需要。

## 这次改动

196条现有题目逐条分为L1基础识记、L2单步应用、L3多步辨析、L4阅读综合，普通基准分别15、25、40、60秒。另为6条逃生路线阅读分级。

本题时间＝（等级基准＋场景补时＋化学重答补时）×当前答题时间倍率，取到0.1秒。

六档乘数依次为：简单1.30、普通1.00、困难0.88、地狱0.78、极限0.68、神级0.58。正式考试+3秒、56选一+6秒、体委任务+4秒；化学口头题每多回应一次+1.5秒。全部先加再乘，只乘一次。

学科作答不再叠加低专注、快速课时、英语强化等隐含缩时。七日挑战使用原有逐日插值，在开题时锁定当前倍率。题目和抽题范围不因为档位而删改。

每题上方显示等级、总时限，可展开公式。进入 **设置 → 查看题目分级与时间表** 可查看规则；新手教程新增“题目等级与用时”，总计14章。

较长的逃生读题时限配套自然追击保护：路线／学科回忆／56选一读完整段预算，基础自然损失至多4／6／8点，再乘原追击倍率。错误后果与神级规则未修改。

## 常用操作

| 操作 | 键盘 |
|---|---|
| 听课／作业／魔方／手机／观察 | 1—5 |
| 纸条／睡觉／国际象棋／讲话 | 6—9 |
| 收好／快速反应步骤 | 空格，必须独立按下 |
| 对话继续 | Enter |
| 课堂四选一 | 1—4，对应屏幕顺序 |
| 暂停 | Esc |
| 全屏 | Alt + Enter |

正式考试只显示“看别人的答案”和“传小抄”这两个风险动作，正常卷面选项仍可独立作答。试卷答题不会因为打开风险动作而停表。

数字快速反应不是知识题：触屏点击提示所指的数字，键盘输入该数字按钮从左到右的位置。条件反射则需要松手静止。本次两种机制及归家藏手机时限都未改动。

## 模式和保留内容

单日、七日、独立归家、六档难度、真实模式收缴、随机课表、课间、晨交、卫生、办公室、国际象棋、反光镜、后门影像、同学状态、彭望梓友情及可选支线、恐怖设置、默认关闭的对话语音继续保留。彭望梓保持美化蝶结发卡、猫耳、无猫尾的造型，所有现用化名保留。

## 存档与升级

先在v3.7.1导出JSON，再在新版导入。旧版正在作答的题目保留原题、排列、原时限和剩余时间，不重抽、不补时。新生成的下一题才使用分级计时。新题的等级、倍率与补时明细同样保存。

暂停、教程、切出页面、离线与读档准备不扣答题时间。展开题内的公式说明不是暂停。

自动保存与检查点重试仍可用。浏览器本地存储不是云存档；无痕、清理数据、换浏览器、移动本地HTML位置可能影响记录，请导出JSON备份重要进度。真实磁盘持久恢复在本次测试环境中受到访问策略拦截，没有计为验收通过。
