# 高二（2）班：最后一节课

> 17:30 以前，不要相信任何一次下课铃。

**版本：v2.1 — 魔方输入修复、传纸条与睡觉**

单文件 HTML 校园恐怖潜行游戏。六节课、教师巡逻、后门检查、Galgame 对话、数学 Boss、最终逃生和 12 个结局均保留；本次在 v2.0 完整游戏上升级，不是独立演示或局部补丁。

全部运行代码和资源都在 `index.html` 内。没有外部 JavaScript、CSS、框架、CDN、图片或音频文件，没有后端和云存档。教室由 DOM/CSS 绘制，声音由 Web Audio 合成。桌面浏览器为主要操作平台。

## 1. 开始与升级

解压后用浏览器打开 `index.html`，选择开始游戏、快速模式或继续上次游戏。只运行游戏不需要安装 Python、Node.js 或测试依赖，也不需要构建。

**保留旧进度的升级顺序：旧版“存档 → 导出备份”，然后新版“存档 → 导入备份 → 继续”。** 请先保留旧 HTML 和导出的 JSON，不要先清除浏览器数据。

v2.1 沿用 v2.0 的存储键、记录格式和结局编号。读取 v2.0 中途记录时，会自动补齐纸条、睡觉和输入缓存字段，把五按钮顺序扩展为七按钮顺序；课程、资源、随机题目、剧情位置及已解锁结局保留。新格式的纸条、睡觉记录不保证能够交给 v2.0 旧游戏继续运行。

直接打开本地文件时，应保持浏览器、文件位置和文件名不变；搬动文件或更换浏览器前先导出。没有继续按钮时，可直接导入之前导出的 JSON，不必重新开始一天。

可选的静态服务器运行方式（电脑已安装 Python 3）：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开：

```text
http://127.0.0.1:8000/
```

这只是提供静态文件，不增加后端或账号系统。切换运行地址前导出备份，在新地址导入。

长按不等于重复操作。紧急三步反应和魔方公式都应逐次按下、松开。

## 3. 魔方组合键修复

先按 `3` 打开魔方，再完成：

```text
R → U → Shift+R → Shift+U
```

不方便使用组合键时，直接用：

```text
R → U → Q → E
```

也可按顺序点击 `R`、`U`、`R′`、`U′`。其余四个面的逆转按钮也已补齐，共 12 个正／逆转按钮。

### 本次修复内容

旧版每两次转动之间要求至少经过 0.1 秒游戏时间，过快的独立按键会被直接忽略。v2.1 删除这个丢键限流；同一模拟帧内输入完整公式也能正确识别。长按防重复只依据按键自动重复事件，不再丢弃独立的快速按下。

键盘优先读取物理按键 `code`，缺失时回退到 `key`。左右 Shift 均可，CapsLock／大写字母本身不会被误当成逆转。编辑框、输入法组合事件及 Ctrl／Command／Alt 浏览器快捷键不会作为魔方转动处理。

每组仍增加 **4%** 魔方进度、恢复 **15** 点专注、降低 **10** 点无聊，并保留 **2.2 秒**组间归位。归位期间可以预输入，最多缓存 **8 步**；面板明确显示已接收的动作、缓存和倒计时。归位结束后按顺序执行，不需要重复按。

切换行动、按空格收好物品、遭遇危险或进入剧情时，尚未执行的缓存会清空，避免之后自动乱转。缓存本身参与自动存档；从中断记录恢复时不会在暂停期间执行。

输入法正在组合文字时，面板会提示切换英文输入或点击按钮。不同系统的实体输入法未逐一实测，`Q/E` 和点击按钮是无需 Shift 组合的替代入口。

## 4. 传纸条

按 `6` 打开纸条，选择话题。写好、折起、递向同桌、等待回条共需要 **5 秒有效课堂时间**。纸条没有送达前，不会获得奖励。

| 话题 | 收到回条后的效果 |
| --- | --- |
| 帮我望风（`A`） | 同桌在接下来的 25 秒留意后门与老师靠近，给出文字提醒；专注 +3、无聊 −5 |
| 放学一起走（`S`） | 计入本节的同桌互动；专注 +4、无聊 −8 |
| 借一下笔记（`D`） | 得到本节课堂重点；专注 +8、无聊 −6 |

专注和无聊仍受 0—100 上下限约束。纸条摊在桌上和传递途中仍有怀疑风险，传递阶段风险更高；老师和后门巡查不会暂停。收到回条后需要间隔 **8 秒**才能再传。

按空格、切换行动、被点名、遭遇巡视或进入下一阶段，会中止尚未送达的纸条，不会发放该张回条奖励。已经送达的回条和望风效果不会因普通收起纸条而被撤销；望风不是无敌，也不会代替紧急隐藏操作。

成功的“放学一起走”和“观察 → 同桌”共用每节课的互动记录：**同一节只计一次，三节不同课程的互动可以解锁同行选项**，之后仍需完成逃生才能得到“一个也不能少”。纸条不会代替六条调查线索的观察条件。

最近 **12 张回条**可在手记中回看。草稿类型、传递进度、间隔、望风剩余时间、成功次数和回条历史都参与存档。

## 5. 睡觉

按 `7` 伏桌小憩，默认 **12 秒**，也可选择 **6／12／18 秒**总时长。睡觉按实际经过的有效课堂时间恢复专注：每秒 **+2.4 专注、−1.2 无聊**，不会增加听课时间。

睡觉会增加怀疑，睡过 4 秒后风险更高；英语强化模式仍会影响怀疑增长。课堂时间、教师移动、随机事件和后门巡查继续运行，**睡觉不等于暂停**。

按空格、再次按 `7`、点击“醒来”或选择已经达到的较短目标时长，可以立即起身。到目标时长会自动醒来，之后不再计算睡觉收益。

老师靠近时，原有三步反应改为：

```text
醒过来 → 坐直拿笔 → 看课本
```

仍需连续三次空格或按顺序点击。没有及时反应会增加怀疑，不会被误算成手机被抓。点名、剧情和下课也会中断睡觉。

睡到较深时可发现一则梦境手记，同一周目只记录一次，不是新增结局。当前睡眠进度、目标时长、累计睡眠时间及梦境标记都会保存；暂停、离线和读档准备期间不计时、不发放收益。

## 6. 保留的主线和系统

主线仍为六节课 → 数学 Boss → 真／假下课铃 → 放学分歧 → 最终逃生 → 校门冲刺。语文、化学、生物、物理、英语、数学的原有机制、手机四个应用、观察调查、作业、手记和 12 个结局保留。

v2.1 **没有增加结局数量**，但成功传递同行纸条现在也能满足已有同行路线的互动前置条件。详见 [结局攻略（含剧透）](./结局攻略_含剧透.txt)。

普通模式前五节各 180 秒课堂计时，数学课 240 秒；快速模式每节 90 秒。剧情、挑战、暂停和逃生时间另计。

全屏与窗口模式均按 16∶9 等比例缩放。切到后台、窗口失焦或退出页面全屏时自动暂停。闪烁、震动、音量、文字速度等可在设置中调整。

## 7. 自动保存与失败重试

每约 **5 秒有效游戏时间**、关键操作和剧情转场都会更新自动记录。网页隐藏、失焦、`pagehide`、`freeze` 等事件触发时，尝试立即保存并暂停。

恢复记录后先显示确认界面，再留 **2 秒准备缓冲**。离线时间不会被补扣到课堂、纸条、睡觉或挑战倒计时。

自动记录和安全检查点分开保存。普通与快速模式均可在 Game Over 后选择“从最近检查点重新出发”。保留最近 12 个检查点，另存本节开头、放学分歧和手动存档；失败画面不会把可重试快照覆盖掉。已解锁结局不会因回读更早记录而消失。

| 本地存储键 | 用途 |
| --- | --- |
| `last-class.progress.v2` | 主进度；v2.1 继续使用 |
| `last-class.progress.v2.backup` | 备份记录 |
| `last-class.offline.v1` | 结局、设置、最佳记录、手机限制 |

新增玩法使用状态字段 `mechanicsVersion: 1`，外层存档格式仍为版本 2。校验值用于发现损坏，不是加密或防作弊。

**自动保存不是云存档，也不保证任何中断都零丢失。** 浏览器强制结束、突然断电或存储拒绝时，最多只能恢复最近一次成功写入的记录。看到存储警告时，请在关闭前导出 JSON 备份。重要进度建议定期导出；清理浏览器数据、移动 HTML 或切换运行地址前尤其如此。

同一份存档发生多标签页写入冲突时，会停止覆盖并提示处理。尽量只在一个标签页游玩。

游戏发布只需要 `index.html`，测试与文档不参与运行。开发测试需要 Python 3.10+、Playwright 和 Chromium；这些不是游戏运行依赖：

```bash
python -m pip install playwright
python -m playwright install chromium
python tests/test_legacy.py --chromium /实际路径/chromium
python tests/test_v21.py --chromium /实际路径/chromium
```

源码中可搜索以下入口：`normalizedKeyCode`、`cubeTurnFromKey`、`turnCube`、`updateCubeQueue`；`startNote`、`deliverNote`、`updateNotes`；`startSleep`、`wakeSleep`、`updateSleep`；`migrateDeskState`、`validateDeskState`。

原有存档入口仍是 `captureSnapshot`、`restoreSnapshot`、`autoSave`、`rememberCheckpoint`。定时玩法使用统一游戏时钟，不依赖离线墙钟或不可序列化的回调。

### 测试边界

以随包 [测试说明](./测试说明.txt) 和 JSON 报告为准。测试包含真实 Chromium 按键、点击和全屏调用，以及未改写生产 HTML 的真实动画循环检查。可控资源单元场景会暂停随机巡逻并拉长课程；原主线另用真实行动和加速时钟贯通。

中断恢复使用模拟 localStorage 并重建新文档；测试环境阻止本地文件导航，因此**没有验证关闭真实浏览器后重开时的磁盘持久保存**。Safari、Firefox、系统输入法和手机真机未逐一实测；响应式视口检查不等于手机硬件验收。自动化通过也不等于已完成长期人工难度平衡测试。
