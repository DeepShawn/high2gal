# 高二（2）班：最后一节课
## v3.11 · 镜面与目光

一个可离线运行的单文件网页游戏。`index.html` 内包含 HTML、CSS、JavaScript、题库、四语词典和程序音效。无需后端、CDN、外部图片或安装运行依赖。

## 开始游戏

使用桌面浏览器打开 `index.html`。主菜单选择单日、全周或归家，选择难度和标准／快速课时。学习模式默认关闭；开启后题量、读题预算和课堂进度速度沿用 v3.10 的学习规则。

手机打开同一文件，在设置中开启“手机端模式”。它使用独立排列的界面，而不是把电脑界面简单缩小。顶部保留系统按钮与黑板场景，底部固定操作栏，中间内容可以滚动。

全屏：点击“全屏”或按 `Alt + Enter`。浏览器不允许全屏时会提示，游戏仍可继续。浏览器缩放、系统导航栏和全屏行为依设备而异。

新玩家可先打开“新手教程”。DeepShawn 继续担任讲解员；练习与正式周目隔离。

- 简单、普通仍自带镜子；后四档改为连续答对2／3／4／5道高中物理题后领取。取得后的镜子需取出、限时观察，并可能因频繁使用引来关注。

- 修正手机控件重新挂接、遗留禁用标记、遮挡层、归家面板变换和窄屏课表溢出。考试、教程和晨间专属任务期间的限制仍然有效。

## 先分清两种挑战

**条件反射：松手，不要动。** 普通0.75秒准备后需要连续静止3.6秒。明显按键、点击、拖动或滚动会失败；准备结束后仍按住按键或手指也算没有停下。极小抖动、松键、抬手、暂停和全屏不直接处罚。

**快速反应：按提示完成隐藏。** 简单两次空格，普通三次；困难至神级分别3／4／5／6个数字。触屏点目标大数字；键盘按目标按钮从左到右的位置。不要对数字快反保持静止，也不要在静止挑战里连按空格。

本次没有提高快速反应处罚：非真实模式一般课堂基础怀疑+36、数学+48；真实模式沿用到100%与收缴规则。条件反射的失败后果沿用原规则，修改的是反应准备与静止要求。

## 镜子与回头

持有镜子不等于一直看得见后门。点取出后等待，镜面可用时才获得视野，观察时间到会收回。提前收起、切换行动或进入阻塞事件也会结束本次观察。反复取镜有警觉预警，继续暴露可能触发快速反应。

没有镜子时使用回头；有镜子也可以选择回头。回头需要1.15秒，再提供4秒视野。基础脚步、门把手、文字预警和同学提醒机制保留，不会要求必须有镜子才能规避危险。

后四档寻镜在原有自由时段找体委进行，体委睡着时不能领取。答错或超时整组重来；当前休闲／学习解题时间仍然适用。真实模式被收走的镜子本周目不能再领。

## 保存与升级

推荐升级前先在旧版“存档”中导出 JSON，随后在新版导入。请保留一份未覆盖的旧备份。

- 自动保存、失焦暂停、中断恢复、手动存档和检查点重试保留。
- v3.10 已有的镜子保留，导入后默认处于收好状态，不倒扣物品。
- 旧版正在进行的静止挑战保留原总时间、剩余时间和容错；下一次才使用新参数。
- 新版存储连续寻镜进度、已抽题目、取镜／观察剩余时间、使用历史、NPC睡眠时间和朱潇巡课状态。
- 新题和新任务的读档不会补满时间或重新抽签；教程和暂停不消耗正式计时。

本地存储不是云存档。无痕模式、清理浏览器数据、换设备或移动本地文件可能影响记录。强制终止进程时，只能恢复最近一次成功保存的状态。

## 文件与开发

- `index.html`：完整可玩的游戏。
- `人物档案.md`、`新手教程.md`、`平衡性调整.md`：本版说明。
- `CHANGELOG.md`、`测试说明.txt`：变更与实际验证范围。
- `tools/base_v3_10.html`：本次更新使用的原始基线。
- `tools/update311.js`、`tools/update311.css`、`tools/locales311.json`：本次增量源码。
- `tools/build311.py`：使用 Python 3 标准库从基线重建 `index.html`，不联网。
- `tests/`：自动检查及最终 JSON 报告。测试才需要 Playwright 与 Chromium，游戏运行不需要。

在本目录执行 `python tools/build311.py` 可以重建。`tools/make_locales311.py` 是附带的词典整理脚本，使用本机 ICU `uconv` 生成繁体列；正常重建直接读取已随包提供的词典，不需要 ICU。
