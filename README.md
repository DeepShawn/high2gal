# 高二（2）班：最后一节课

## v3.3「门后的晚安」

单文件校园／卧室恐怖潜行游戏。新版加入郭自嘲的两句语录、尹莎莎的点名禁睡事件，以及可独立游玩、也会自动接入全周挑战的 **“归家”**。当前共有 **26个结局、94项成就**。

人物、学校、家庭及情节均为虚构，不是对同名现实人物的描述。人物机制见 [人物档案.md](人物档案.md)。

## 运行与全屏

用桌面浏览器打开同目录 `index.html`。全部 HTML、CSS、JavaScript、国际象棋规则和程序音效都在这个文件里，不需要安装依赖，不使用后端、外部图片、音频、框架或 CDN。`tests/` 只供开发测试，不影响游戏运行。

点击 **“全屏”** 或按 **Alt + Enter** 切换。浏览器拒绝请求时会提示；退出全屏、切出页面或失去焦点会暂停。返回后手动继续，不会把离线时间扣进课堂或卧室倒计时。某些浏览器／设备的全屏能力不同，未实测的平台不保证表现一致。

## 三种开局

| 模式 | 流程 |
|---|---|
| 开始新的一天／快速模式 | 保留随机全天学校流程，07:20到校、21:40放学；不会强制追加卧室。 |
| 一周挑战 | 星期一至星期日，每天完成学校并成功离校后，**自动进入当晚归家**；过完这一晚才能进入次日。周日也有卧室，不能跳过。 |
| 归家 | 主菜单直接进入卧室，可选标准或快速；不需要先打完学校。 |

六档难度保留：简单、普通、困难、地狱、极限、神级。标准／快速只决定时长，难度在开局固定。**神级明确无法通关**，卧室与全周也不能绕过闭环。

## 归家：先藏手机，再装睡

故事时间为 **22:10—23:00**，压缩为标准 **180秒**、快速 **90秒有效操作时间**，另加阅读及收尾检查。目标不是一直装睡：必须在期限内完成对应的手机使用目标，并且当晚被发现不足三次。

普通难度要求标准累计用手机 **36秒**、快速 **18秒**。进度条持续显示要求与已完成时间；不必连续玩满，安全时段可以分次累计。

| 操作 | 键盘 | 鼠标／触屏 |
|---|---|---|
| 拿出手机、亮屏 | 4 或 P | “玩手机” |
| 第一步：熄屏、藏手机 | 按一次空格 | 点击“藏好手机” |
| 第二步：躺下、装睡 | 再按一次空格 | 点击“躺下装睡” |
| 剧情继续 | Enter | 屏幕上的继续按钮 |
| 暂停／静音／全屏 | Esc／M／Alt + Enter | 顶部对应按钮 |
| 存档／设置 | 顶部按钮 | 顶部按钮 |

两次空格必须独立按下；长按不会自动完成两步。**手机藏好但仍坐着，不算躲过检查。** 已经躺下时不需要反复按键。

父母会经过走廊、停在门边，或直接转动门把手推门。真正开门前有文字和门把手预警；普通难度门把手预警 **1.15秒**，随后另有 **2.8秒**完成两步。进入房内后还会观察片刻，再退出。不要仅凭门关上就马上亮屏，应等提示确认脚步离开。

每次检查最多记一次被发现；同一次检查被抓后再亮屏不会重复扣次数，也不能继续刷手机时长。**三次不同检查被发现**触发《卧室里的亮光》。当晚超时但手机目标未完成，也会失败。失败可以从卧室入口或最近安全检查点重试。

第一场真实检查一定会入室；后续有路过不入室和突然推门变化。到23:00时若检查尚未结束，需要处理完该次检查才结算，此时不再补手机时长。没有无提示的即时失败。

家中使用独立的“备用手机”，与学校手机限制、课堂怀疑、手机被抓次数及“不用屏幕也能出去”等学校统计分开。单独归家不会代替学校毕业证或推进全周天数。

## 全周：一个白天加一个夜晚，才算完成一天

新开全周流程为：当天15个校园阶段 → 成功离校结果／逃生 → 当晚卧室 → 日结 → 次日07:20。星期日至23:00完成最后一晚，才解锁《走过七次放学铃》。校内坏结局和主动留校分支不推进天数，也不会自动进入卧室。

每晚有独立的目标、父母事件和被发现计数。越到周后段，父母检查间隔略短；**反应窗口不随天数缩短**。夜间失败重试当晚，学校成功结果已保存在卧室检查点，不必重打白天。

七天课表开局时生成并保存。每天上午5节、下午4节、两节晚自习，体育每天0—1节，允许同科两连堂、不允许三连堂。随机结果与习题课标记不因刷新改变。午晚餐、午休、体育与家长晚自习继续保留。

日间资源、纪律与同学统计按天重置；国际象棋局面与战绩跨天保留。全局成就、结局和解锁日期保留。本模式允许检查点重试，不是铁人／反作弊认证模式。

## 新语录与英语禁睡

数学教师当前显示名为 **郭自嘲**（上一版“郭自朝”），仍是同一个数学、后门和办公室角色。以下两句进入数学课实际开场对白：

> 你们的计算能力太有限了，我建议你们以后可以开一家公司，计算能力有限公司。
>
> 都说你们这一届学生很牛，但看来也不过如此。

尹莎莎在英语课堂事件中说：

> 梁子辕open your eyes。

全班安静，正在小憩的玩家立刻醒来，**本节真正下课前不能再睡觉**；睡眠按钮禁用，键盘7也不能绕过。点名不会额外记一次被抓。事件按课堂进度出现，也可能因为课堂中睡觉提前触发；每节只触发一次。下一节解除，不会无限延长到全天；若下一节仍是英语，会作为新的一节独立触发。

禁睡、安静效果、点名状态会存档。完成这节英语课才解锁隐藏成就《全班都醒了》，仅触发后退出不计。

## 校内操作与既有机制

| 功能 | 按键 |
|---|---|
| 听课／作业或本节习题／魔方／手机／观察 | 1／2／3／4／5 |
| 纸条／睡觉／国际象棋／讲话 | 6／7／8／9 |
| 收好物品、停止讲话、收棋或醒来 | 空格；睡觉也可再按7，禁睡期间不能开睡眠 |
| 魔方公式 | R → U → Shift+R → Shift+U，或 R → U → Q → E |
| 纸条／讲话话题 | 面板按钮或 A／S／D |
| 国际象棋 | 点棋子和合法落点；或方向键选格、Enter确认 |
| 兵升变 | 后／车／象／马按钮，或 Q／R／B／N |
| 暂停／手记／静音 | Esc／N／M |
| 人物／课表／成就／存档 | 右上角按钮 |

**条件反射**仍为 v2.2 的松手静止。普通难度准备1.4秒、连续静止1.4秒，一次明显误动作容错。

**学校快速反应**仍为简单2空格、普通3空格，困难起分别3／4／5／6数字按钮；本版没有重新压缩这些窗口。数字模式触屏点大数字，键盘按目标按钮从左到右的位置键。**归家两步隐藏是独立机制，不会把普通课堂改成两次空格。**

国际象棋保留8×8合法走法、将军、将死、易位、吃过路兵、升变及游戏化自动和棋；使用轻量AI，不是专业棋力引擎。课堂下棋不暂停巡视。纸条、后排罚站、办公室、吃饭搜包、同学援助、后门登记和原有结局均保留。

## 恐怖模式

设置中的 **“恐怖模式 · 校园与归家”** 默认关闭。开启后增加更暗的卧室、异常倒影、剪影、低声和异常文字；真实门边预警仍优先显示。

恐怖效果与父母事件使用分离的逻辑，不改变检查抽签、目标时长或反应窗口，不借开启特效偷偷加难度。音量、闪烁和震动分别受原设置控制，静音仍有完整文字预警。

## 存档、迁移与备份

有效游戏时间每5秒和关键操作尝试自动保存。自动记录与安全检查点分开，失败不覆盖之前的重试点；支持手动保存和JSON导入／导出。

归家保存当前动作、手机时长、两步隐藏进度、父母的当前阶段和剩余计时、已抽取结果、难度、周内日期及校园成功结果。读档先确认，再有2秒准备缓冲；不重抽父母，不因关闭网页直接走完整晚。

**升级前先在旧版导出JSON，再到新版导入。** v3.2 已完成日结的日期不会被迫补打一晚，也不会凭空增加“七声晚安”；未完成的当前日及后续日期接入归家。完整体验七晚、取得实际七晚成就应新开一周。v3.1及更早中途校园记录仍保留原课表，不在半途强行重排。

本地记录不是云存档。清理浏览器数据、无痕环境、移动HTML路径或浏览器限制可能影响保留。突然终止进程不能保证最后一次操作写入，恢复以最后成功记录为准，重要记录应额外导出JSON。
