# 高二（2）班：最后一节课 — v3.19「课后捉迷藏」

本版以 v3.18 已发布的完整 HTML 为基础，修复电脑端五夜入口，保留经典海胆苹果五波对战，新增独立捉迷藏。

## 运行

打开同级 `index.html`。游戏本身不需要安装依赖、后端、CDN 或外部素材。网页标题、顶部版本与底部离线版本统一为 3.19。

主菜单新增“独立游戏 · 各自存档”分区，可看到四种入口：

| 入口 | 内容 |
|---|---|
| 海胆苹果 · 经典五波 | 原版海胆监测弹与外星贯穿，两技能、三路、五波；保留原学习模式、徽章、存档。 |
| 海胆苹果与外星人 · 战术对战 | 已有的扩展战术流程，继续使用原规则与独立档案。 |
| 五夜守夜模式 / 旧楼五夜 | 先勾选启用，再点击“旧楼五夜”。启用偏好保存；首次使用默认关闭。 |
| 课后捉迷藏 | 新增的独立三轮关卡，可直接开始，不需先通关校园。 |

较矮的窗口可在主菜单内部滚动，不会把入口铺在校园按钮上。

## 五夜入口修复

旧版主菜单复选框位于设置弹框之外，缺少对应的设置事件绑定。用户勾选后，界面刷新会按旧的 `nightWatch=false` 将它还原，启动按钮也一直禁用。

本版给这个主菜单复选框单独接入设置保存事件；勾选后即能启动，刷新菜单、二次进入仍保留选择。设置页原开关继续生效。五夜玩法参数没有改变。

## 捉迷藏

你是躲藏方，搜索方由电脑同学控制。不是联机多人模式。

依次完成阅览室、器材室、美术走廊三轮。每轮收集三个金色徽记，再到绿色集合点；紫色信笺是可选收集。每轮入口、通道和目标位置明确，不靠无法判断的随机瞬间抓捕。

墙体阻挡视线，搜索者看到你会提高“被发现”进度，到100%失败。蓝色柜子可以藏身，但屏息有上限；搜索者贴近柜门时会检查。奔跑和诱饵可以改变他们的追踪目标。倒计时结束也会失败，可以从本轮起点重试。

| 压力 | 每轮上限 | 搜索者 | 一次完整屏息 | 本轮诱饵 |
|---|---:|---:|---:|---:|
| 舒缓 | 210秒 | 1 | 16秒 | 4 |
| 普通 | 180秒 | 2 | 13秒 | 3 |
| 紧张 | 150秒 | 3 | 10秒 | 2 |

收集完就可以离开，不需要等时间耗尽。压力设置属于捉迷藏，不改变校园的七档难度、真实模式或学习模式。各轮之间有明确结算，不把校园课程插入其中。

### 操作

| 动作 | 键盘 | 手机 / 鼠标 |
|---|---|---|
| 移动 | WASD / 方向键 | 按住方向按钮移动，松开停止 |
| 奔跑 | 按住 Shift | “奔跑”开关，再使用方向按钮 |
| 藏身 / 出来 | E | 蓝色柜子上点击“藏身” |
| 向前投声音诱饵 | Q | “诱饵”按钮 |
| 倾听最近搜索者的方向 | 空格 | “倾听”按钮 |
| 暂停 | Esc | 顶部“暂停” |
| 本模式说明 | F1 | 顶部“玩法说明” |
| 全屏 | Alt + Enter | 顶部“全屏” |

捉迷藏期间这些按键只作用于本模式，不会同时启动校园道具或校园教程。

## 独立成就与结局

新增九枚捉迷藏勋章、五条结局，集中在“捉迷藏档案”。本模式胜利不发校园毕业证、不改校园全收集范围。具体条件见《捉迷藏玩法与档案.md》。原经典、战术、五夜的档案全部保留。

## 保存和升级

校园、经典五波、战术、五夜、捉迷藏分别使用原有或独立记录。升级前在旧游戏中导出要保留的各模式 JSON，然后在新版对应模式中导入；校园 JSON 不包含独立模式的进度。

捉迷藏每5秒有效游玩及关键操作保存，在每轮开头建立检查点。保存剩余时间、角色位置、随机状态、搜索目标、收集物、屏息、体力和勋章。恢复时先暂停，继续后给2秒准备；离线不追算时间。返回主菜单后仍可续玩。

“导出捉迷藏备份”使用单独格式，拒绝把其他模式的 JSON 导入，已解锁档案在回档后保留。存储失败会提示，重要进度应另存 JSON。浏览器本地记录不是云存档。

## 布局与性能

电脑为地图与操作分栏；窄屏为单列地图和触控区；横屏手机调整为较窄侧栏。顶部、滚动内容、底部保存提示分开。暂停 / 结算时背景控件置为 inert，避免被遮住的按钮仍然响应。反复进入复用同一个界面节点。

新增模式共用原游戏的动画循环，没有叠加第二个常驻循环。背景地图缓存，画布绘制最多约30次/秒，状态文字仅在变化时更新；帮助、暂停和退出停止有效模拟。独立模式期间跳过无用的校园界面更新。

新增捉迷藏文本覆盖现有八种语言。旧游戏的历史翻译范围不因本次更新扩大，不宣称完整旧剧本已全部翻译。

## 构建与测试

完整源文件：`tools/base_v3_18.html`。新增逻辑：`tools/hide319.js`；新文本：`tools/locales319.js`；样式：`tools/style319.css`。

在本目录执行：

```sh
python tools/build.py
```

即可重新生成相同的 `index.html`，不需网络。`tools/hooks319.js` 仅在显式测试开关中暴露测试接口；普通运行不创建该接口。

自动测试脚本在 `tests/`，需独立准备 Python、Playwright 和 Chromium；这些不是游玩依赖。测试覆盖范围、原始报告及限制见《测试说明.txt》和《性能说明.md》。

手机真机、Safari、Firefox、长期发热和完整七日流程本次未重新验收，不承诺任何设备绝无Bug或恒定帧率。
