## 运行

打开 `index.html`。游戏代码、样式和程序绘制资源全部内嵌，不需要安装运行依赖。

电脑默认沿用原布局。手机在设置中开启手机端模式。右上角全屏按钮或 `Alt + Enter` 切换全屏；`Esc` 暂停。浏览器是否准许全屏取决于所在运行环境。

## 本版新增操作

1. 按 `2` 或点击“作业”，第一次会先选择语文、化学、生物、物理、英语或数学作业。
2. 工具区的 **“作业本 / 领回”** 可更换要写的科目、查看暂收记录和对应老师。电脑沿用左侧可滚动工具区，手机沿用原滚动工具区。
3. 化学课写课外作业可能被李方琳注意。看到预警后按空格或换成听课，可以避免这次暂收。
4. 继续写到确认点后，该本作业会被暂收，并明确转交给对应科目的任课老师。只有这一本被锁住，其他物品和已完成的总作业进度保留。
5. 等到课间、午休或允许自由活动的时间，打开“作业本 / 领回”，点击待领本子的“去办公室领回”。
6. 先找对老师，说明经过，约定补写时段，完成3秒核对，再点击“取回作业本”。流程不会自动跳过下一节课。

学校明确安排的**本节化学习题**可以正常写，不按这项新机制处罚。考试、晨间收作业和罚站等原有限制继续生效。

## 存档及旧功能

暂收记录、所选科目、预警抽签、办公室位置、对话阶段、签收倒计时和领取结果都接入原存档系统。未领取的作业可跨日保留。暂停、离线和读档缓冲不完成签收。

旧 v3.17.1 存档中没有新暂收事件的，不会凭空产生处分或新成就。建议先在旧版导出校园 JSON，再在本版导入。真实关闭浏览器后重新打开的磁盘持久保存，未能在本次受限环境中完成验证。

- 真实模式的永久收缴仍然有效；本支线不能归还被真实模式永久没收的整类道具。

没有修改七档难度、快速反应数量、反光镜、四倍课时或自定义流速。校园与归家合计 **64条结局档案、229项成就**；旧独立对战、战术对战及守夜的成就与存档保持独立、不增删。

## 从构建材料重建

游戏本身不需要这一步。修改源码后可用 Python 3 运行：

```bash
python tools/build.py
```

构建以未修改的 `tools/base_v3_17_1.html` 为基底，顺序插入本版数据、语言、玩法和样式，输出单文件 `index.html`。`tools/build-info.json` 记录文件大小和 SHA-256。
