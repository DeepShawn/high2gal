# 高二（2）班：最后一节课
## v3.5.2 · 新手教室

在 v3.5.1 化名修正版上新增独立新手教程。游戏主体仍是单个 `index.html`，无后端、无外部运行依赖；全部样式、场景、音效、国际象棋和教程代码都在文件内。

本次没有调整课堂数值、人物、结局与成就门槛：正式内容仍为 **32 条结局、124 项成就**。所有人物沿用同姓、同音或近音化名，彭望梓仍是有天生猫耳与猫尾的猫娘。

## 运行与入口

解压后用浏览器打开 `index.html`，或直接保存这个 HTML 文件运行。用代码编辑器打开同一个文件即可编辑完整源码。

主菜单新增 **“新手教程”** 按钮；顶部 **“教程”**、暂停页、设置页、生存手册、读档恢复页、正式考试弹框和归家顶部也提供入口。键盘 **F1** 打开／关闭教程；小屏主菜单另有一个未被16∶9舞台缩小的“新手教程 · 从这里学”按钮。

全屏仍为 **Alt + Enter** 或界面的全屏按钮。新手教程有独立全屏按钮，横屏和竖屏均能阅读、练习，不要求旋转手机才能退出。

## 新手教程教什么

14章按从入门到实操组织，可以按顺序学，也可以直接跳到需要的章节：目标与模式、三条资源、危险预警、空格快速反应、数字位置输入、静止条件反射、课桌活动、答题与考试、晨交／卫生／办公室、课间用餐和班长、老师与同学、归家、存档重试、五题入门小测。

不只提供长篇说明：资源切换、后门预警、空格隐藏、数字隐藏、保持静止、魔方公式、考试停止冒险、卧室隐藏和检查点都有可操作教学；其他章节配有即时反馈小测。顶部有练习暂停，章节内有重置按钮。

数字模式始终区分：**触屏点击目标大数字；键盘按目标按钮的左起位置**。慢速讲解不限时，并额外显示键盘对应顺序；正式计时关闭额外答案辅助，使用游戏中的基础难度配置。教学设置不会改当前周目或下一局的难度。

首次可先在教程学会普通三次空格、数字位置和松手静止，再回到主菜单尝试简单难度＋快速单日。这只是一条学习路径，不会替玩家更改设置或自动开始新的一局。

## 教程与正式记录隔离

打开教程前尝试保存一次实际游戏进度，随后暂停正式游戏的时钟、教师、后门、题目、隐藏和归家检查。练习不调用正式行动函数，不累计手机使用、被抓、作弊、关系、成绩或成就，也不会建立正式安全检查点。

从游戏中退出教程时，先回暂停页；从已有设置或其他系统页进入时，回到原系统页。不会在退出瞬间自动让限时题或追逐继续。

教学记录只包括所在章节、已读、练习完成和入门小测完成时间，保存在独立的 `last-class.tutorial.v1` 本地记录中。**它不是游戏存档，也不随正式 JSON 备份迁移。** 刷新后会记住章节，但未做完的教学练习安全地重新开始；正式游戏中途进度仍按原有存档方式恢复。教学存储被拒绝时显示提示，不阻止阅读和练习。

切出页面或窗口时，练习也会暂停，回到页面后要手动继续。教学没有恐怖闪烁、突发音效或强制的感情支线，不会替玩家开启任何恐怖设置。

## 考试怎么操作

正式考试目前由同科连堂第二节的“三题课堂测试”触发。三道试题属于同一场考试，每一题均执行本版规则。普通课堂口头提问、生物静止、快速隐藏和逃生机关不被误当成笔试。

考试期间普通课桌动作及其相关面板全部隐藏并设为不可交互：听课、作业、魔方、手机、观察、纸条、睡觉、国际象棋、讲话、玩具、卫生和班长互动等都不能借旧快捷键绕过。

**上方仍保留试卷答案。直接独立答题即可完成考试，下方的冒险动作不是必选。** 底部课桌动作只剩两项，并且只在考试时出现：

| 动作 | 操作 | 时间与效果 |
|---|---|---|
| 看别人的答案 | A 或点击同名按钮 | 持续2.4秒；成功后给出两个可能的参考答案，不自动交卷 |
| 传小抄 | S 或点击同名按钮 | 持续3.6秒；成功后给出一个建议答案，有20%机会是错误答案 |

再次点击正在执行的同名按钮，或按空格，立即停止。停止后没有未完成收益。数字 **1—4** 仍用于提交上方的卷面答案，不会切换旧课桌动作。

同一题同一种动作成功完成后不能重复刷提示。正在执行其中一项时，另一项不可启动。所有动作共享当前试题倒计时，传递小抄不会暂停试卷。

暂停、手记、存档、音量和全屏属于系统控制，不在课桌动作限制之内；小屏考试弹框内提供手记、暂停、全屏。触屏按钮与键盘遵循同一套状态机。

## 讲台监考和后果

所有正式考试的监考教师都**坐在讲台**，无论原先是哪一门课、是否巡走、是否习题课。考试覆盖原来的走动、卫生代整理、后门巡视和同学望风；考试结束后恢复原行为，至少留出2秒巡视缓冲。

每次冒险操作开始时抽取一次是否引起注意，结果存档。会被注意的动作在0.8秒时出现“停止翻页、看向你”的预警，持续到1.8秒才确认。预警期间停止可避免本次确认；静音也能看到文字和高亮。

| 难度 | 看别人的答案：引起注意 | 传小抄：引起注意 |
|---|---:|---:|
| 简单 | 20% | 30% |
| 普通 | 32% | 46% |
| 困难 | 44% | 58% |
| 地狱 | 54% | 68% |
| 极限 | 64% | 78% |
| 神级 | 74% | 88% |

这是每次动作的抽签概率，不是每帧反复抽签。预警、已抽出的结果、动作进度与试卷时间都保存，读档不重新抽取。

确认后本题作废，任何答案均记零分；本场仍可以继续。每次独立动作最多登记一次，已经作废的本题不能继续刷作弊动作。考试登记与手机被抓、快速反应失败分别统计，避免误判成玩手机或睡觉。

**本周目累计三次独立确认后，老师向游戏内家长发送一次消息**，其中包含“经常造假”的角色台词。可通过手记查看发信人、日期、时间和累计次数。没有网络发送、联系人访问或摄像头调用。

全周模式的考试登记跨日保存，新开局清零。获得消息后，下一次进入归家开场会增加一次父母对话；同一条消息不会每晚重复演出。普通课堂纪律仍按原规则每日结算。

## 存档与升级

自动记录继续每5秒有效游戏时间进行，关键动作与转场也保存。暂停、网页隐藏与中断的原有处理保留，恢复后有准备缓冲。失败不会覆盖掉可重试的安全检查点。

**升级前先在旧版导出 JSON，在新版导入。** 本版兼容v3.5及原先可读的旧版本中途状态。v3.5记录只更新姓名，不更改考试计数、题目排列、剩余时间或已解锁日期。v3.4的旧考试仍按既有迁移流程处理：旧考试迁移为讲台监考，保留当前题目、答案排列和剩余时间；新增考试计数从零开始，不凭空补造旧作弊记录。旧版口头化学题继续按原口头题处理。

旧存档的显示姓名、对白、手记、聊天和检查点标签在内存迁移及重新导出时替换为化名。内部角色ID、成就ID和结局ID不变，不撤销已解锁日期。归家、国际象棋、作业和其他校园进度保持原有迁移规则。

存档是当前浏览器中的本地记录，不是云存档。重要进度请另存JSON备份。本次真实关闭浏览器后重开的本地文件存档测试被环境策略拦截，未计为通过；重要进度请保留独立备份。
