# 高二（2）班：最后一节课 · v3.17.1
## 立绘重叠与渲染性能修复

打开 `index.html` 运行。完整代码、美术和游戏资源仍在单个 HTML 内；不需要安装游戏运行依赖。本版以 v3.17「夜巡与异星」实际交付文件为基础，不合并之前同版本号的其他分支。

## 修复内容

1. 手机人物容器不再画旧的身体底色、边框和阴影。新版立绘使用专用 `div.cast-figure316`，姓名样式只匹配姓名标签，修复旧人物轮廓和深色方块同时压在新立绘后面的现象。
2. 每个角色节点只允许一个立绘容器；缺失时补建，重复时清理。切换课程、返回教程或设置、读档和切换电脑版／手机版，复用同一个容器，不复制角色或交互按钮。
3. 横屏与平板下移除了底部操作栏遗留的 `translateX(-50%)`；底栏现在服从既有网格布局，不再有半栏移出屏幕。横屏立绘与姓名位置单独适配，避免在140像素预览中裁掉姓名。
4. 考试坐姿与讲台家具、主动观察才可见的家长举机提示保留；修复不会把真实危险提示一起隐藏。

## 性能调整

- 翻译改成增量处理：只有变化的文字和属性进入翻译，语言改变才重扫整页；保留原文映射和八语回切规则。
- 对白文字、数值和简单状态相同则跳过DOM写入；只有字数、台词对象或相关状态变化才更新对白。对重复播放同一句台词也能正确重新显示。
- 课表圆点、怀疑值与继续按钮不再无变化地重建内部HTML。没有修改浏览器的DOM原型。
- 一个外层界面更新批次只做一次翻译收尾；设置、教程停留期间不反复刷新隐藏的校园界面。
- 底栏尺寸改由ResizeObserver提供，避免在逐字对白与多层渲染函数中反复强制计算布局。
- 复用原动画循环，为人物位置增加轻量更新；界面、列表保持原有较低刷新频率。没有额外开启第二套永久动画循环。

## 更新与兼容

先在旧版导出JSON备份，再在本版对应模式导入。校园、夜巡、战术对战的存档格式均未改变；本版不更改难度、课时、题库、快反窗口或成就结局条件，不重抽进行中的题目。导入独立模式仍按原规则暂停，并保留2秒恢复准备。

全屏：按钮或 `Alt + Enter`。暂停：`Esc`。手机模式仍从设置开启。

原八语覆盖范围和系统声线限制沿用v3.17。本补丁没有补翻尚未完成的旧剧情／题库，也没有更改声音系统。
