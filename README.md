# 高二（2）班：最后一节课 · v3.13「海胆与星客」

基于本次提供的 v3.12「课时与节奏」源码更新。运行文件只有 `index.html`，HTML、CSS、JavaScript、四语文本、题库、SVG角色和合成音效全部内嵌。游戏运行无需安装依赖，不需要后端或联网服务。

## 开始游玩

打开 `index.html`。原来的单日、七日、归家和学习模式入口保留；新玩法从主菜单 **「对战模式 · 独立单人 · 三路防守」** 进入。正在校园中时，请先保存并返回主菜单，再进入对战。

这是单人对抗教师投影的独立关卡，不是联网多人对战。对战有独立难度、学习开关、存档、结果和徽章，不覆盖校园进度。语言仍跟随全局语言偏好。

电脑支持键盘和鼠标。校园手机模式仍从设置开启；对战页面按屏幕宽高自行重排，不需要额外安装手机版。全屏使用界面按钮或 `Alt + Enter`；浏览器不允许全屏时仍可窗口游玩。

## 本次魔方修复

原版实际输入判定只有 `R U R′ U′`。本版将显示、判定、切换、存档和教程统一到四组不同的四步序列：

| 组别 | 序列 | 键盘例子 |
|---|---|---|
| 1 | R U R′ U′ | R、U、Shift+R、Shift+U（或 R、U、Q、E） |
| 2 | L′ U′ L U | Shift+L、Shift+U、L、U |
| 3 | F R F′ R′ | F、R、Shift+F、Shift+R |
| 4 | B′ L′ B L | Shift+B、Shift+L、B、L |

完成后按1→2→3→4自动轮换；也可点击组号选择。切换只清除当前未完成步骤和预输入，不重置归位冷却，不发奖励。每组仍增加4%，完成25组到100%。每次正确顺序才结算，重复刷新不发放新收益。

保留全部面转按钮、左右Shift、Q/E替代键和最多8步预输入。归位期间的预输入按照下一组公式处理。收好魔方后清空未执行队列，不在后台继续转动。新手教程的魔方练习也有四组选择，练习记录不污染校园状态。

本游戏仍是简化的公式输入小游戏，不是完整的三阶魔方物理模拟器，四组序列也不是完整CFOP教程。

## 独立对战

三条路线、五波进攻，共35个教师投影。投影到达防线扣一点防线值，降到0失败；处理完五波后仍有防线值即获胜。部分后段投影半透明，可由海胆揭示。两位新角色的轮廓取自用户提供的手绘草图。

| 技能 | 基础效果 |
|---|---|
| 海胆苹果：监测海胆 | 消耗20能量，单体伤害23，移动速度×0.45持续4.5秒；揭示同路目标6秒；基础冷却1.8秒 |
| 外星人：外星贯穿 | 消耗32能量，同路最多命中3个目标，各伤害35；移动速度×0.75持续2秒；基础冷却3.1秒 |

冷却最终还乘对战难度的冷却系数。能量上限100并自动恢复；空路不会扣能量。海胆飞行0.42秒，外星脉冲0.32秒，实际到达后才结算命中。

| 操作 | 键盘 | 触屏/鼠标 |
|---|---|---|
| 选左/中/右路 | A/S/D，或左右方向键 | 路线按钮 |
| 发射海胆 | J | 监测海胆按钮 |
| 外星攻击 | K | 外星贯穿按钮 |
| 学习题回答 | 1—4 | 答案按钮 |
| 暂停 | Esc | 暂停按钮（题目弹框内也有） |
| 全屏 | Alt + Enter | 全屏按钮 |

对战神级只使用独立战场参数，没有校园的180秒闭环；它不解锁任何校园神级出口或毕业成就。本次代理在神级第五波失守，已验证其失败和本波重试；不宣称已验证神级通关或真人平衡。

## 对战学习模式

在对战开局页勾选，默认关闭，和校园的学习开关相互独立。

开启后，每次申请发射任一种技能，都必须先答对一题。出题本身不扣能量、不发射；答对后点击「发射并继续」，该次许可只发射一次。答错、超时或取消均不发射，也不扣能量，返回战场后有1.2秒短冷却，下一次重新出题。

从既有题库抽取非语文的L1/L2题；同一轮题池用尽前不重复。倒计时为该题普通等级基准×当前难度的答题倍率，四舍五入到0.1秒。原有普通档倍率1.05继续保留，例如L2为25×1.05=26.3秒。

读题和看解析时，战场移动、能量恢复、冷却和波次时钟冻结；题目自己的倒计时继续，手动暂停后题目也停止。不会让玩家在读题时被敌人无提示越线。取消问题不能刷能量。

## 校园海胆道具

在课间、体育、午休等可自由操作的时段，找醒着的体委 **王梓锐**，点击「找体委 · 海胆苹果」。每天最多领取一份，共2发，携带上限2发；不是每回档一次就能再领。她睡着时不能领取。校园中不提供外星贯穿技能。

上课自由行动期间点击「发射海胆」。消耗1发，飞行0.4秒后，当前教室移动速度×0.45持续6秒，同时提供后门真实巡视监测；冷却25秒，发射增加基础怀疑4点，再受原规则修正。跨课程不继承减速。拿到剩余弹数及每日领取记录可跨日保存。

它不冻结老师的目光、不删除已确认违规、不抹除照片、不暂停快速反应，也不会让固定讲台的老师凭空移动。考试、罚站、晨间作业锁定、限时事务和归家时不能使用。

## 存档与升级

升级前，先在旧版导出校园JSON备份，再在新版的校园存档菜单导入。实际v3.12魔方中途记录已检查：原进度和步数保留，默认从第一组继续，不凭空生成其它组完成次数。既有四倍课时及自定义流速保持原样。

校园道具纳入原自动存档、检查点、导入导出。独立对战使用另外两个本地存储键：`last_class_battle_v313` 和备份键 `last_class_battle_v313_backup`。每5秒及关键行为保存；切出页面会暂停并保存。恢复时保持原题、选项顺序和中途状态，并留2秒准备。

对战JSON请从对战页面单独导出/导入，不能当作校园JSON使用。失败可从最近波次开始点重试；检查点保留进入该波时的防线和能量，不自动补满。开始新对战前会确认是否覆盖对战进度。缺少浏览器存储权限时提示失败，建议立即导出。

浏览器本地文件的存储和全屏行为因设备与权限而异。断电、强制结束或清理浏览器数据无法保证保留最后一次操作；重要进度应额外导出。这里没有云存档。

## 源码与重建

直接编辑 `index.html` 即可修改。需要可重复构建时，使用Python3运行：

```bash
python tools/build313.py
```

构建输入是随包保留的用户v3.12基线 `tools/base_v3_12.html`、`tools/update313.js`、`tools/update313.css`。构建脚本只用Python标准库，无需下载资源。游戏本身不需要Python。

自动测试需要另行安装Python Playwright和可用Chromium。测试只用于开发，不是运行游戏的依赖。运行命令及真实测试边界见 `测试说明.txt`。
