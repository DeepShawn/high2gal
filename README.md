# 高二（2）班：最后一节课 · v3.17「夜巡与异星」

单文件网页游戏。双击 `index.html`，或把它放到自己的静态站点运行。不需要安装游戏运行依赖；`tools/` 和 `tests/` 只用于开发与验收。

**本版范围说明：** 法语、俄语、冰岛语、阿拉伯语已经进入语言菜单，新增独立模式的操作、规则、结局、勋章和主要界面已翻译。部分旧剧情与旧学科题仍使用明确标注的英文回退，**不是完整八语剧本**。语音采用浏览器语音合成，未内置八套录音；设备缺少声线时会提示。

## 从哪里进入

| 入口 | 功能 |

## 校园变化

真实恐怖游戏增加心神压力和三类限时异象，而不只是更换色调。12秒内通过放下手机、观察讲台或确认后门应对；正确维持动作2—3秒才化解。未处理增加压力，100点进入专属失败。普通巡视和真实模式收缴照常存在；旧恐怖视觉开关、闪烁、震动和音量仍独立。

家长拍摄不再有自动预警条、倒计时或拍摄前群提醒。第二节晚自习，需要主动观察讲台或老师，才能看到举起手机。普通难度举机1秒，之后照片立即记录／录像继续4秒。体委睡着时不提醒；清醒时每次独立有10%机会提醒。同一次拍摄只抽一次并保存结果。拍摄完成后的群上传通知仍保留。

学校新增3条档案和9项成就：现为61条校园结局、218项校园成就。新增守夜与战术档案**不并入这些数字**。

## 旧楼五夜：按键

`A/D`：左右门；`Q/E`：左右门灯；`Space`：监控；`1—4`：切换镜头；`L`：声音诱饵；`R`：重启监控。手机使用对应按钮。

每晚150秒有效时间，模拟00:00—06:00。五晚逐步提高敌人压力。一直关门会耗尽电力；监控、重启和诱饵也有成本。左边机械海胆、右边外星人会靠近，废弃广播室的钟面人需要监控或诱饵压制。完整说明见 `旧楼五夜玩法.md`。

## 战术对战：按键

`A/S/D`：左／中／右路；`J`：海胆监测弹；`K`：贯穿；`L`：停滞；`U`：显形信标；`I`：屏障修复；`O`：超载。鼠标／触屏可以点路线或战场，再点技能。

六种普通敌人加首领，三条路线，每波后选择升级。学习模式中题目计时、战场冻结；正确后点击确认才发射。答错或取消不消耗能量、不发射。公式答案与数字键不穿透到校园。

## 存档与迁移

升级前先在 v3.16 导出校园JSON，随后在本版校园存档入口导入。旧版进行中的照片／夜晚按旧状态衔接；没有发生过的新异象和拍摄观察不会补造。真实恐怖默认关闭。

校园、旧楼五夜、新战术、旧经典对战分别保存。新独立模式每5秒有效游戏时间以及关键操作自动保存；失焦、隐藏页面会暂停并保存。每晚或每波入口有检查点。恢复后有2秒准备。暂停和离线不消耗夜间时间、答题窗口或技能冷却。

独立模式的「导出／导入本模式备份」只处理对应模式，不是全游戏统一备份；不能把五夜备份导入战术。导入会确认替换对应进度和档案。校园备份沿用原格式。

本地记录不是云同步。实际关闭浏览器后的磁盘持久保存测试被本环境访问限制拦截；页面重建、JSON与模拟存储恢复已验收。重要进度请另存JSON。

## 语言与声音

支持选择：简体中文、繁體中文、English、日本語、Français、Русский、Íslenska、العربية。阿拉伯语文本使用RTL；数字快反、国际象棋与战场的物理左右方向不倒转。

语音默认关闭。开启或点击试听属于一次明确的播放动作；提供缺少声线、等待加载、静音、被阻止等状态。可以点击「重试语音」。本地声线优先；「允许浏览器联网声线」默认关闭，开启后浏览器可能把对白交给其语音服务。游戏本身没有第三方TTS接口、账号或API密钥。

## 手机／电脑

电脑是原分区布局，新模式使用独立全屏画布和操作区。手机校园采用顶部系统栏、中间独立滚动、底部动作栏三段布局；不会让固定底栏压住中间按钮。内容较长时需要滚动，工具区不会凭空消失。横屏战术操作置于侧栏；小屏也可独立滚动题目和说明。

## 文件结构

- `index.html`：完整可玩的交付文件。
- `tools/base_v3_16.html`：本次构建所用的原版完整源码。
- `tools/*317.js`、`tools/update317.css`：本版功能、语言与布局源码。
- `tools/build.py`：标准库构建；执行 `python tools/build.py` 重建相同HTML。
- `新增八语词典.json`：可编辑参照用词典，实际编译源位于两个 locale JS 文件。
- `tests/`：自动检查、输入代理、运行结果。测试依赖Python Playwright与Chromium，不是游戏依赖。

测试范围与未完成项目见 `测试说明.txt`；需求对应关系见 `逐项验收.md`。
