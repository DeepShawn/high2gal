# 高二（2）班：最后一节课 · v3.16 掌心与水声

单 HTML 离线校园游戏。基于 v3.15，新增智能手机、班级群影像、家庭询问及洗澡流程，并更新具名人物立绘与界面。

## 运行
打开同目录 `index.html`。不需要安装运行依赖。电脑为默认布局；设置里开启手机端模式可使用重新排列的界面。
全屏：右上角按钮 / Alt + Enter。Esc 暂停。部分浏览器需要在独立窗口中打开 HTML 才允许全屏。
游戏中的 QQ、抖音、影像和家长消息都是离线模拟；没有实际账号、摄像头、麦克风、联网视频或真实消息发送。

## 手机
按4或点击“手机”打开。新增主屏、状态栏、应用图标与独立滚动区域：
- QQ：班级群 **2025级二班**。任课教师按实际课堂发布任务；已有系统发出的真实同学提醒同步到群中。可以记下作业、回复提醒。
- 抖音：四张程序绘制的模拟短内容卡，可切换、喜欢；不是联网的短视频流。
- 小游戏：三种图形匹配，有结果反馈及奖励冷却。课堂奖励每4秒最多一次，正确匹配专注+2。
- 作业：筛选教师任务；点击“记下这项作业”才统计阅读。
- 相册：查看本周保存的课堂照片与录像。
- 时钟：展示当前校园/夜间游戏钟面，不替代真实的下课条件。

手机使用不暂停巡视、资源变化或父母检查。底部“收好手机”或空格可隐藏；归家时按原来的多步快反规则完成装睡。
手机在教室和卧室复用同一个 DOM，不是两个重叠的面板。重开应用保留上次页面；底部房屋按钮返回主屏。

## 值班家长拍摄
只在第二节家长监督晚自习发生。每天生成三个错开的随机时点，各次独立决定照片或录像。
先有3秒举机预警；照片记录快门时的一帧，录像记录4秒中的五个关键帧。记录的是玩家实际动作，包括拍摄中途抬头。
影像发布到班级群并可打开。录像需要手动播放满4秒才算完整观看，不打开相册不会自动发放观看成就。
这是游戏状态生成的插画记录，不是截取现实摄像头或浏览器录像。
低头写作业也会出现在画面中，但不自动记为玩手机、作弊或处分。录像期间及时收好仍可能避免后续被拍到，但不会删除此前已拍下的帧。

## 回家：询问、收纳、洗澡、夜间
单日成功离校、七日每晚均接入新归家前置流程；独立归家也有洗澡。学校失败/留校分支不会当作正常回家。
单日先保存原学校结果，完成当晚后回到原结果页。夜间失败可以重试夜间，不要求重打当天校园。
流程：可能发生的家长询问 → 选择手机位置 → 放好手机2秒 → 洗澡 → 取回 → 原卧室关卡。

有当天低头影像时，独立抽取：
- 65%概率询问“你低着头在下面做什么？”
- 45%概率在洗澡时检查手机。
没有当天低头影像，不发起这两项新增事件。抽签进入夜晚时固定并存档；刷新不重抽。
解释会区分实际玩手机、写作业及其他动作，不强行让玩家承认影像没有证明的违规。

手机位置：
| 位置 | 有搜查时 |
| --- | --- |
| 熄屏放进带盖收纳盒 | 安全，不被本次搜查发现 |
| 桌面 | 会被发现 |
| 枕头下 | 会被发现 |

位置选择都有明确提示。必须先完成放置才能去洗澡；进浴室前可重新选择。洗澡中不可换位置。
快速洗澡12秒、标准20秒，完成后专注+8（最多100，只结算一次）。洗澡界面只有浴室陈设、水声和磨砂玻璃，不显示洗浴人物。
洗澡时暂停原卧室时钟、手机目标累计和原父母巡查；不是用洗澡抵扣偷偷玩手机的目标。
没被发现则取回手机进入原夜间；搜出手机进入《浴室外的亮屏》，可重试洗澡前检查点。

## 画面与布局
20位具名/身份角色采用带服装、发型、五官和配饰的缓存矢量立绘。猫耳班长和体委保留各自外观区别，无猫尾。
教室黑板、桌面、工具区、动作按钮、对白、菜单、QQ与浴室采用统一墨绿/青灰配色。
电脑分区保持；手机打开时压缩底部动作区为可横向滚动的一排，留出手机内容空间。小屏内容允许独立滚动，不强行塞进一屏。
打开手机会定位到应用区域，减少第二次进入仍停在工具区的问题。

## 存档与升级
先在 v3.15 导出 JSON，再在新版导入。
已验证实际 v3.15 的题目中途和归家中途快照迁移。旧记录没有新照片，不补造记录或新成就。
已经开始的旧版夜晚继续原流程，不在夜间一半插入洗澡；下一次新夜晚才使用新前置流程。
新数据包含消息、影像帧、播放进度、询问/搜查抽签、放置位置、洗澡剩余时间及按日成就。恢复后沿用已有2秒缓冲。
本地存储不是云存档。清理数据、无痕窗口、移动本地文件、不同浏览器都可能使存档不可见；重要进度请导出备份。
七晚安全收纳要求同一个周目实际完成七晚，旧周目已完成夜晚不会凭空补齐。

## 构建与测试
运行 `python tools/build.py` 可从随附 v3.15 基础源码与本版扩展重新生成完全一致的 `index.html`。
测试需要 Python、Playwright、Chromium（不是游戏运行所需依赖）：
`python tests/run316.py`
完整流程可用 `python tests/run316.py --flows`。脚本使用模拟存储与手动游戏时钟，并读取题目答案，不能代表真人难度。

测试范围、性能数据与未验收项目见 `测试说明.txt`。不能保证任意浏览器、设备、系统缩放比例都无重叠或固定60FPS。
