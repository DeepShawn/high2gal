# 最後の授業 — v3.10「四言語の教室」

`index.html` をブラウザーで開くと遊べます。ゲーム、スタイル、問題集、オフライン翻訳、描画素材は一つのファイルに含まれます。外部の翻訳サービスやCDNは使いません。初期設定はパソコン向けです。設定の「モバイルレイアウト」で小さい画面向けに並べ替えられます。全画面表示はボタンまたは `Alt + Enter`、一時停止は `Esc` です。

## 表示言語と読み上げ

メインメニューの言語、または設定から、簡体字中国語・繁体字中国語・英語・日本語を選べます。旧版の英語コア版を置き換え、会話、問題と解説、人物紹介、ガイド、記録、結末、システム表示を新しい辞書に接続しました。

英語の試験で実際に問われる英文や単語は英語のままです。問題の指示や解説は選んだ言語になります。数式、数値、キー表記、内部ID、正解の位置は変更しません。言語を切り替えても問題を引き直さず、残り時間を補充しません。会話は一文全体を翻訳してから少しずつ表示します。

読み上げは**初期設定で無効**です。設定で会話読み上げを有効にできます。四つの音声カードで、標準中国語、台湾華語、英語、日本語の対応するローカル音声を確認・試聴できます。

音声は録音済みファイルではなく端末とブラウザーの音声合成です。対応音声が端末にない場合は全文と通知を表示し、別言語で代読したり、音声をダウンロードしたりしません。マイクにもアクセスしません。

言語変更、次の台詞、一時停止、ページを離れる操作で古い読み上げを中止します。後から音声が読み込まれても、取り消した台詞が突然再生されることはありません。四言語の選択と読み上げ内容は模擬音声で検証していますが、全端末に四種類の音声があるという保証ではありません。

## リアルモードの英語授業

リアルモードで始めたゲームでは、英語授業の導入、教室表示、問題、会話が一時的に英語になります。読み上げが有効なときだけ音声も英語になり、無効なら無音のままです。

この切替で好みの言語を上書きしません。英語授業中に言語設定を変えると、授業後に戻す言語が変わります。他教科、休み時間、職員室、帰宅、脱出、メニューは選んだ言語に戻ります。英語授業中のセーブを読み込んだ場合も同じ規則を適用します。通常モードの英語授業は、試験素材の英文を除いて選んだ表示言語を使います。

## セーブと既存機能

パラメータ違いを含む学科問題1,036問（うち数学56択75問）、結末48種類、実績174種類を維持しています。学習／カジュアル、難易度、一週間、帰宅、没収、チェス、体育、交流、反応課題のルールは変更していません。

旧版でJSONバックアップを出力し、新版に読み込めます。問題、選択肢の順番、正解番号、残り時間、進行状態は保たれ、日本語の設定も保存できます。ブラウザー保存はクラウド保存ではないため、ファイルや端末を変更する前にバックアップを保管してください。

## 構築と検証

`tools/build.py` は保存したv3.9本体、英語・日本語の翻訳TSV、追加辞書、ICUの繁体字変換から単一HTMLをオフラインで再構築します。構築にはPython、BeautifulSoup4、ICU `uconv` が必要ですが、遊ぶだけなら不要です。

正確な検証項目は中国語のテスト報告とJSON結果をご覧ください。機械的な翻訳漏れ・変数整合性の確認は、母語編集者や高校教員による全問題の校閲の代わりにはなりません。実機の発音品質や未検証ブラウザーを検証済みと扱っていません。
