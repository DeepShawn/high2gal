# 高二（2）班：最后一节课

> 17:30 以前，不要相信任何一次下课铃。

**v2.3 — 数字顺序条件反射、触屏适配与专项平衡更新**

完整的单文件 HTML 校园恐怖潜行游戏。六节课程、教师巡逻、后门检查、逐字对话、数学 Boss、最终逃生、12 个结局、六档难度、36 项成就、传纸条、睡觉、全屏、自动保存和检查点重试均保留。

全部运行代码和资源都包含在 `index.html` 中，没有外部脚本、图片、音频、框架、CDN 或后台服务。运行游戏不需要安装 Python、Node.js 或测试依赖。音效由 Web Audio 合成，场景由 HTML/CSS 绘制。

## 运行与升级

解压后打开 `index.html`，选择难度，再开始标准或快速流程。标准/快速只改变课堂长度，不是难度选项。源码可以直接用文本编辑器打开。

**保留进度升级：在旧版“存档 → 导出备份”，再在新版“存档 → 导入备份 → 继续”。** 不要先删除旧文件或清理浏览器数据。浏览器本地存储不是云存档；文件路径、浏览器、存储权限改变时，原记录不一定可直接读取。

v2.0/v2.1 记录沿用已有迁移逻辑，默认普通难度。v2.2 记录保留原难度、属性、结局、成就、纸条、睡眠、对话和检查点。

旧版尚未结束的“保持静止”反射无法逐步对应新玩法，因此**只将这一道未完成的旧题转为本难度的新题，给一次完整准备和操作时间**；其它进度不重置。同一旧记录产生相同排列，转换后的 v2.3 记录再次读取不会换题或补时。v2.3 中途数字反射记录不承诺能回退给旧版读取。

## 条件反射：新版操作规则

本次替换的是**生物课及逃生中的生物回忆**。不再要求鼠标和键盘保持静止。物理课的“脚步停后静候三秒”和普通巡视三步隐藏保持原规则。

### 普通及以上：看提示，点数字

上方为一排随机排列的数字按钮，下方为需要完成的数字顺序。两排都使用 1—N 各一次。提示全程可见，当前步骤有边框，完成项打勾；一题开始后，排列不会在输入中途改变。

**触屏/鼠标：** 按照下方提示，点上方大数字相同的按钮。

**键盘：** 从左到右的位置固定对应数字键 `1—6`；按目标数字所在按钮的**位置键**，不是直接照抄随机按钮上的大字。每个按钮下方都标有“键 1”“键 2”等位置提示。主数字行和数字小键盘均支持。

```text
例一（按你的原例）：
按钮大字：1 2 3 4 5
下方提示：4 2 5 1 3
键盘输入：4 2 5 1 3

例二（按钮被打乱）：
按钮大字：3 1 5 2 4
对应按键：1 2 3 4 5
下方提示：4 2 5 1 3
键盘输入：5 4 3 2 1
触屏点击：数字4 → 数字2 → 数字5 → 数字1 → 数字3
```

准备期不接收、也不缓存输入；提前按键不会扣容错。开始后每次独立按键只推进一步，长按自动重复不算新输入。数字被本弹框接管，不会同时切换手机、纸条或睡觉。无关字母、越界数字、组合输入、释放按键、鼠标移动不计数字反射失误。

### 简单：仍是三次空格

依次按下并松开三次 `Space`，对应“抬头 → 拿笔 → 看书”。触屏可依次点三个步骤按钮。仅当前步骤的触屏按钮可用，不需要匹配随机数字。

### 各难度时间

所有档位先给 **0.6 秒准备**。下面“操作时间”不含准备；不受低专注、英语强化或通用答题倍率再次缩短。

| 难度 | 按钮/操作数 | 操作时间 | 含准备总时间 | 误按规则 |
| --- | --- | ---: | ---: | --- |
| 简单 | 三次空格 / 三步按钮 | 3.0 秒 | 3.6 秒 | 无数字匹配；超时失败 |
| 普通 | 4 个数字 | 4.4 秒 | 5.0 秒 | 首次误按扣 0.35 秒 |
| 困难 | 5 个数字 | 5.0 秒 | 5.6 秒 | 首次误按扣 0.40 秒 |
| 地狱 | 5 个数字 | 4.4 秒 | 5.0 秒 | 首次误按扣 0.45 秒 |
| 极限 | 6 个数字 | 5.0 秒 | 5.6 秒 | 首次误按扣 0.50 秒 |
| 神级 | 6 个数字 | 4.4 秒 | 5.0 秒 | 首次误按扣 0.55 秒 |

普通及以上保留**一次误按容错**，不会清空正确步骤，也不会重抽数字或重置倒计时。第二次误按失败；首次误按扣时使剩余时间归零也立即失败。未完成全部步骤不能靠等待自动成功。

### 本次平衡调整

课堂中顺序挑战独占事件层，教师不会在操作期间同步巡逻；结束后至少留 **2 秒**巡视缓冲，已有更长保护时间不会被缩短。成功仍为基础怀疑 −2、专注 +3×资源收益倍率；失败仍为基础怀疑 +8，并只应用一次难度/强化修正，不算学科答错。

逃生中的生物反射：准备 0.6 秒不扣自然追击距离，输入阶段自然追击减半；失败仍只扣基础 10 距离，再应用本难度损失倍率，成功增加基础 10 距离，再应用收益倍率。用较慢的数字查找代替旧静止事件，不应额外承担双重惩罚。

神级仍按有效游玩时间在 180 秒必败，所有成功/替代出口封锁；数字准备、读提示和输入的有效时间照常计入神级生存时钟。只有暂停、阻塞剧情、离线和读档缓冲不计时。神级不是可通关难度。

其它资源数值保持 v2.2：魔方普通专注 +9、归位 3.2 秒；纸条完成后间隔 10 秒；睡觉疲劳、醒后 8 秒间隔、手机热度、作业效率等不额外修改。完整参数见 `平衡性调整.md`。

## 全屏与触屏

右上角“全屏”或 `Alt + Enter` 切换全屏。数字反射弹框也有独立“全屏”和“暂停”按钮，退出全屏自动暂停。请求被浏览器拒绝时保留正常窗口游玩。

反射弹框单独按视口适配，不再和整间教室一起缩小；在测试的 320—1920 像素宽视口中，六按钮仍保持一排，按钮触控目标至少 44×44 CSS 像素。竖屏可直接完成反射，其它课堂面板仍建议横屏使用。按钮只通过一次 click 路径结算，触摸产生的指针事件不会另算一步。

触屏测试是 Chromium 设备模拟，不等于 Android/iPhone 实机验收。

## 常用操作

| 场景 | 操作 |
| --- | --- |
| 自由课堂 | `1` 听课、`2` 作业、`3` 魔方、`4` 手机、`5` 观察、`6` 纸条、`7` 睡觉 |
| 普通巡视 / 惊醒 | 逐次按三次 `Space`，或按三个步骤按钮 |
| 普通课堂收起物品 | `Space` |
| 新版生物反射 | 简单三次 `Space`；其它难度按数字按钮位置键或点大数字 |
| 魔方 | `R → U → Shift+R → Shift+U`；也可 `R → U → Q → E` |
| 纸条 | `A` 请同桌望风、`S` 约好同行、`D` 借课堂笔记 |
| 睡觉 | 6/12/18 秒可选；再次 `7`、`Space` 或“醒来”结束 |
| 对话 | `Enter` 显示全文 / 继续 |
| 限时选择 | `1—4` 或点击选项 |
| 系统 | `Esc` 暂停、`N` 手记、`M` 静音、`Alt+Enter` 全屏 |

魔方支持左右 Shift 和 8 步预输入；组间归位时间依难度 2.8—3.8 秒。切换行动或遇到事件会清空未执行输入。

纸条传递需要 5 秒有效课堂时间，完成后才给回条与收益。不同课程中至少三次同行互动可开启原有同行路线；同节重复不增加课程计数。

睡觉不是暂停，老师与危险仍会运行；小憩收益受难度和疲劳影响。

## 存档、中断与重试

每 5 秒有效游戏时间、关键操作、剧情转场和网页中断事件尝试保存。自动记录与安全检查点分开，Game Over 不覆盖此前可重试记录。主菜单“继续”读取自动记录；失败页可从最近检查点重新开始，也可到存档菜单选择本节开头、放学分歧、手动记录或较早检查点。

v2.3 会保存数字按钮排列、提示、已完成步数、剩余时间、误按次数和反馈状态。网页恢复后先暂停，再给 2 秒准备缓冲；不在离线期间扣时。反复回档不累加同一段操作的成就计数。

存储被禁用或配额不足会提示；可手动导出 JSON 到本机。强制终止进程或断电不保证触发最后一次保存，因此只能保证使用最近一次**成功写入**的记录。备份不是加密/防作弊或云端验证系统。

## 成就与结局

成就仍为 36 项，结局仍为 12 个。条件反射成就改名为**“反应有序”**：零误按完成一次顺序挑战，简单三空格也计入。沿用原 `reflex` ID，旧版“稳住呼吸”的解锁时间与状态不会被清除。

其它成就、难度毕业证、神级 60/120/180 秒成就保持原规则。成就无属性加成。详见 `成就说明.md`；结局触发条件放在 `结局攻略_含剧透.txt`，默认不在此展开。

## 源码结构与调整入口

HTML、CSS、JavaScript 均内联；没有构建步骤。编辑后保存并重新打开即可。主要入口：

| 名称 | 用途 |
| --- | --- |
| `DIFFICULTIES` | 六档总体平衡参数；新增 `reflexCount` 与 `reflexTime` |
| `REFLEX_PREP` / `REFLEX_PENALTIES` | 数字反射准备时间和逐档误按扣时 |
| `createReflexChallenge()` | 生成按钮排列、目标排列及可序列化状态 |
| `reflexInput(slot)` | 统一输入与判定；slot 从 0 开始，表示按钮位置 |
| `renderReflexBody()` / `renderFreezeState()` | 稳定按钮 DOM、步骤、容错、计时与反馈 |
| `migrateReflexSnapshot()` / `validateReflexChallenge()` | 旧静止事件迁移、新版存档字段校验 |
| `updateEscape()` | 数字准备期/操作期追击速度修正 |
| `interactionMotion()` | 只负责物理 `wait`，不处理生物反射 |

内部仍使用 `type: 'freeze'` 和 `startFreeze()` / `finishFreeze()` 名称以延续剧情、事件队列、存档调用；**这些名字不代表新版需要保持静止**。新版挑战对象用 `reflexVersion: 1` 标识顺序结构。存档外层仍为 v2 格式。

正常游玩不暴露测试接口。开发时打开 `?test=1` 可使用 `window.__LAST_CLASS_TEST__`；该模式默认不写磁盘。测试文件不参与游戏运行，也无需随网页部署。不要将调试接口当作防作弊边界。

## 测试与限制

详细实测结果、环境、完整用例和源码 SHA-256 见 `测试说明.txt`。测试包含原系统与 v2.1/v2.2 功能回归、47 项新版专项、真实键盘/鼠标、触屏模拟、界面尺寸、存档重建、全屏与真实动画帧冒烟。

大部分自动检查使用可控游戏时钟、模拟 localStorage 和测试接口；完整主线代理知道答案，不代表真人通过率。实际 Chromium 持久浏览器重启测试曾尝试访问本地文件，但测试环境以 `ERR_BLOCKED_BY_ADMINISTRATOR` 拦截，因此没有把它计为通过。Safari、Firefox、手机真机、强制断电和真人大样本难度校准尚未验收。

只在修改/开发时才需要测试工具：

```bash
python -m pip install -r tests/requirements.txt
python tests/test_legacy.py --chromium /usr/bin/chromium
python tests/test_v21.py --chromium /usr/bin/chromium
python tests/test_v22.py --chromium /usr/bin/chromium
python tests/test_v23.py --chromium /usr/bin/chromium
```

将 `--chromium` 换成自己的 Chromium 可执行文件路径。`tests/README.md` 解释时钟、存储替身和旧用例适配范围。
