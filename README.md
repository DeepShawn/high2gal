# 高二（2）班：最后一节课

## v3.2 · 一周之间

单文件校园恐怖潜行游戏。每天07:20到校，21:40真正放学；在听课、作业、魔方、手机、观察、纸条、睡觉、国际象棋和讲话之间管理风险。人物、学校和情节为虚构。

本版基于提供的v3.1国际象棋版本继续开发：**25个结局、88项成就**。新增随机5+4+2课表、周一至周五挑战、任课教师差异化观察、后排站立、整景恐怖模式和人物档案。原有静止条件反射、数字快速反应、全屏、自动存档、检查点及国际象棋保留。

## 运行与全屏

打开 `index.html` 即可运行，完整HTML、CSS、JavaScript、棋规、轻量AI和程序音效都在同一文件内。无需安装运行依赖，不加载外部图片、音频、框架或CDN。

主菜单的“开始这一天”“快速模式”开启新单日；“一周挑战 · 标准／快速”开启五天。六档难度独立于流程长短，开局后固定，读档不改。

右上角按钮或 **Alt+Enter** 切换全屏。被浏览器拒绝会提示，不中断游戏。退出全屏、切换页面或失焦会暂停，继续时保留准备缓冲。手机可点击按钮，建议横屏。

## 一周挑战

按周一至周五五个上学日设计，不含周末。每天需要完成实际课表并达到有效成功离校结果，才出现夜间日结。失败仍进入原有失败结局，可以从安全检查点重试，不直接跳到第二天。

日结记录本日结局、有效游戏时间和是否无失误。前四晚按“休息一晚”进入次日；周五成功后显示周结局。夜间对话界面、课表、星期与周进度都可保存。

下一天专注恢复100、怀疑和无聊归零，当天作业、魔方、课堂计数、提醒冷却、办公室与手机管理等重置；**国际象棋局面、棋局战绩和已解锁成就／结局保留**。周报告和同一周运行标识继续保留。保存记录中的国际象棋对手不会因跨天重复落子。

《终于不是星期一》：完成五天并成功离校。《空白的五日点名册》：五个日结都没有被抓、快速反应失败、答题错误、后门违规确认和任课违规确认。完美周同时登记普通周完成结局，不必故意失败另刷普通完成。

神级仍有180秒有效游玩的必败闭环，不能通过周模式绕过，也没有必须神级通关才能解锁的周成就。

戴贝贝不走动，但对讲话敏感；被确认后站到本节下课，只能听课或观察。郭自朝不走动，对讲话、睡觉和低头严格。王颖讲授课不走动、习题课走动，两种课型均对低头与讲话敏感。何凤林和尹莎莎会走动。李芳玲保留慢走与突然观察，增加名言“让你受着你就受着”。

体委王子睿的提醒加入“压力，阿妈忒拉斯”。他提醒真实走动，李思聪提醒真实后门。两人的概率从简单到神级依次为65%、48%、34%、23%、14%、7%，个人最短抽取间隔为22、30、40、52、68、85秒。每次危险只抽一次，失败也冷却，不自动替玩家隐藏。

## 条件反射与快速反应不是一回事

**条件反射**恢复v2.2的松手静止：普通准备1.4秒、静止1.4秒，允许一次明显误动作；误动后有0.35秒松手缓冲再重新完成静止。轻微鼠标抖动、松键和系统控制不直接判错。物理逃生的静候三秒独立保留。

**快速反应**在危险接近时主动操作，先准备0.4秒：

| 难度 | 操作 | 操作时间（不含准备） |
|---|---|---:|
| 简单 | 2次独立空格／2步骤 | 2.8秒 |
| 普通 | 3次独立空格／3步骤 | 2.6秒 |
| 困难 | 3数字按钮 | 3.0秒 |
| 地狱 | 4数字按钮 | 3.3秒 |
| 极限 | 5数字按钮 | 3.6秒 |
| 神级 | 6数字按钮 | 3.9秒 |

触屏按下方目标顺序点上方“大数字”；键盘按目标所在按钮从左起的位置键。比如按钮是3、1、5、2、4，提示4、2、5、1、3，键盘应按5、4、3、2、1，而触屏依次点大数字4、2、5、1、3。同一道题和读档期间不换排列。

数字第一次误按扣0.35／0.40／0.45／0.50秒，不清空正确步骤；第二次误按或超时失败。数学只额外减0.20秒、英语强化只减0.15秒，不叠乘低专注等旧缩时。长按不连发，弹框输入不穿透到桌面活动。

## 恐怖模式

设置新增 **“恐怖模式 · 整景压迫”**，默认关闭。开启后整体教室和走廊更暗、更冷，边缘阴影和人影加重，夜间环境异常更密集；按钮、倒计时和实际危险提示仍可读。

旧版轻量“恐怖强化 · 夜校异象”保留。两者共享环境异常计时，不双倍叠加事件。恐怖模式不改变难度、反应时间、搜包概率或怀疑数值，不强制开启闪烁、震动或提高音量。视觉敏感时可关闭闪烁、震动或整个模式。

## 国际象棋及原玩法

8×8棋盘，玩家执白先手，对手为本地轻量AI。支持合法行棋、将军、将死、易位、吃过路兵、四种升变、逼和、常见子力不足、重复局面和五十回合。重复和五十回合采用自动判和简化，没有完整竞赛裁判流程。

上课下棋不暂停，空格可以收好并保留局面，收起后AI不继续落子。国际象棋可跨课、跨周挑战的日界线继续。原有魔方、纸条、睡觉、讲话、办公室、午晚餐手机搜查、体育和家长监督继续可用。

## 存档、恢复与升级

有效游戏时间每5秒、关键操作以及页面离开／隐藏时尝试保存。失败不覆盖安全检查点，保留最近12个检查点及本节、放学分歧、手动记录。主菜单继续或结局页重试，读档先暂停，再留2秒准备。

推荐先在旧版导出JSON，再到新版导入。**旧v3.1中途记录保留原13阶段时间线**，只使用新的教师规则，不把玩家强制退回上午或插入未玩课程。开始新单日／一周才生成新5+4+2课表。已到放学、逃生的旧记录不倒退。更早版本仍经过已有迁移；旧五子棋棋盘不能作为国际象棋继续。

新增课表、星期、日结、站立进度、观察警告、同学冷却和恐怖设置都会保存。暂停和离线不扣站立、题目、睡眠或纸条时间，不重新抽取当前检查结果。

本地存储不是云存档；清理浏览器数据、无痕模式、换浏览器、文件路径变化或禁用存储可能影响记录。强制结束进程不能保证保存最后一次操作。重要进度请额外导出JSON备份。

运行游戏不需要测试依赖。开发测试使用Python、Playwright和Chromium；棋规测试使用Node。可在 `tests/*.py` 中按实际环境修改Chromium路径（默认 `/usr/bin/chromium`）。

```bash
node tests/test_chess.cjs
python tests/test_v32.py
python tests/test_release.py
python tests/test_disk.py
```

其中普通集成测试用模拟存储和可控时钟，不冒充真实关闭浏览器后的磁盘恢复；最后一项专测真实存储，在不允许本机网页导航的环境中可能被拦截。实测范围以 `测试说明.txt` 为准。
