# 高二（2）班：最后一节课

## v3.1 · 动静之间

可离线运行的单文件校园恐怖潜行游戏。在07:20到校、21:40放学的一天中管理怀疑、专注和无聊，经历课堂、体育、用餐、办公室与两节晚自习，再选择离校路线。人物、学校及情节均为虚构。

本版以v3.0源码为基础，保留全天13阶段、原20个结局与60项成就，增加3个结局、18项成就：共 **23个结局／78项成就**。条件反射与快速反应现在是两套不同的玩法。棋类已经替换成国际象棋，不是五子棋换皮。

## 运行

将 `index.html` 保存到固定位置，用桌面浏览器打开。游戏不需要安装依赖，不请求后端，也不从CDN加载资源。完整HTML、CSS、JavaScript、棋规与AI都在此文件中；音效由代码生成，棋子使用Unicode字符。

点击“开始这一天”或“快速模式”。两种流程长度与六档难度互相独立。右上角“全屏”或 **Alt+Enter** 切换全屏；浏览器拒绝请求时会提示，可使用浏览器自己的全屏操作。退出全屏、切换页面或失焦会暂停，回到页面需要继续。手机上的主要弹框与棋盘单独放大，支持点击和触屏。

无需把本说明、测试或攻略放到服务器上，游戏只依赖 `index.html`。直接用本地文件打开时，存储权限与存储位置由浏览器决定；重要进度应另外导出JSON。无痕模式、清理数据、换浏览器或移动HTML可能影响本地记录。

## 条件反射：恢复v2.2的“不要动”

生物课以及逃生中的生物回忆出现“不要动”时，先松手，再保持静止。**这不是点击数字的事件。**

| 难度 | 松手准备 | 连续静止 | 明显动作容错 |
|---|---:|---:|---:|
| 简单 | 1.8秒 | 1.1秒 | 2次 |
| 普通 | 1.4秒 | 1.4秒 | 1次 |
| 困难 | 1.3秒 | 1.5秒 | 1次 |
| 地狱 | 1.15秒 | 1.65秒 | 1次 |
| 极限 | 1.0秒 | 1.8秒 | 1次 |
| 神级 | 1.0秒 | 1.8秒 | 1次 |

准备期内可以松开手。轻微鼠标抖动、松开按键、输入法组合、长按自动重复和系统控制不直接算明显误操作。有容错时，明显动作消耗一次容错，给0.35秒重新松手缓冲，再重新完成本难度的静止时长；超过容错失败。

课堂失败基础怀疑+8，再受难度风险倍率影响；成功恢复少量专注。结束后至少有2秒巡视缓冲。物理课“静候三秒”没有改成数字玩法。

## 快速反应：老师靠近时收好

每次正式快速反应先给 **0.4秒准备**，下表是额外的操作时间，不含准备期。教学练习单独放宽，不计正式操作成就。

| 难度 | 快速反应 | 操作时间 | 数字误按扣时 | 同学提醒概率 | 每人最短间隔 |
|---|---|---:|---:|---:|---:|
| 简单 | 2次空格／依序点2个步骤 | 2.8秒 | 不适用 | 90% | 16秒 |
| 普通 | 3次空格／依序点3个步骤 | 2.6秒 | 不适用 | 75% | 22秒 |
| 困难 | 3个数字按钮 | 3.0秒 | 0.35秒 | 60% | 30秒 |
| 地狱 | 4个数字按钮 | 3.3秒 | 0.40秒 | 45% | 40秒 |
| 极限 | 5个数字按钮 | 3.6秒 | 0.45秒 | 30% | 52秒 |
| 神级 | 6个数字按钮 | 3.9秒 | 0.50秒 | 15% | 65秒 |

简单／普通逐次按空格，或依次点亮当前步骤按钮。困难起，上方的数字排列和下方的目标顺序都会打乱；一题中不会变化。

**触屏／鼠标：** 依照下方目标顺序，点上方按钮的大数字。

**键盘：** 按对应目标所在按钮的左起位置键。每个按钮下方标有“键1”“键2”等，主键盘和小键盘均可。

```text
上方按钮：1 2 3 4 5
下方提示：4 2 5 1 3
键盘输入：4 2 5 1 3

上方按钮：3 1 5 2 4
位置按键：1 2 3 4 5
下方提示：4 2 5 1 3
键盘输入：5 4 3 2 1
触屏点击：4 2 5 1 3（大数字）
```

数字档第一次误按仅扣少量时间，保留已完成步骤；第二次误按或超时失败。扣时后归零立即失败。准备期输入、越界数字、无关字母及鼠标移动不判错。数学课只减0.20秒；英语强化只减0.15秒，不再叠乘低专注、巡逻或难度反应倍率。

正式快速反应失败基础怀疑调整为普通课堂+26、数学+34，再受难度修正；原来分别为36、48。成功仍收好物品，失败仍有原有被抓后果，不是免罚按钮。

## 两位友方同学

**体委王子睿**留意老师走向过道，也会提醒巡走家长。**数学课代表李思聪**留意真实后门巡视。提醒概率和个人冷却见上表，每个事件只尝试一次；冷却中错过的事件不会过后补抽，读档不会重新抽。

提示会写入消息与手记，左侧同学卡显示收到提醒与及时应对次数。NPC不会替你收物品，概率也不表示每个固定秒数一定出现一次提醒。原有脚步、阴影、反光等基础预警保留，幻影、教学和体育自由活动不生成他们的真实巡视提醒。

只有在收到提醒时确实正在做有风险的行动，并在8秒内、危险确认前主动按空格收好，才计一次“及时应对”。后门应对还要求同一次真实巡视、尚未登记。正常听课、反复空格和反复回档不能刷帮助次数。

## 国际象棋

你执白，同桌执黑，8×8棋盘，白方先行。棋规引擎检查合法走法、自将、被将后的应对、王车易位、吃过路兵与兵升变；以将死结束，不是把王吃掉。支持四种升变选择。最后一着和选中棋子的合法落点会高亮。

同桌使用随难度变化的轻量搜索与评价，不是专业国际象棋引擎。搜索按短时间片执行，不能靠AI思考暂停课堂。棋盘打开时课堂巡视照常，空格随时收棋；收起后对手不会在后台继续落子。棋局可以跨课程继续。

和棋支持逼和、常见子力不足、重复局面、五十回合，以及提和。**为减少弹窗，游戏在三次重复或双方各50回合没有兵移动／吃子时自动判和，而不是要求玩家提出裁判申诉；这与正式竞赛的申诉流程不同。** 不包含比赛用棋钟、完整裁判争议处理或穷尽所有“死局”的证明。

“提和”需要双方各走至少10步、当前无升变选择、轮到白方；双方子力差不超过一兵时同桌接受。空棋盘初始化不能直接刷和棋。中途重开需要确认，放弃不算胜、和或完成局。

胜局基础专注+9、无聊−12；和棋基础专注+4，恢复受难度影响。失败不直接罚怀疑。完成局后4秒可开新局。原《终局之外》改为本周目赢 **1盘国际象棋** 即可选择，不再要求三盘五子棋；三胜成就保留为可选目标。

## 成就与结局

右上角成就菜单可筛选，并显示解锁时间与历史最高单局进度。新增内容覆盖快速反应、静止、同学提醒、及时应对、合法行棋、易位、升变、吃过路兵与和棋。

新增结局为《前排与后门之间》《动静之间》《和棋之后》。这些是21:40放学后的独立路线，不在完成某次动作时提前跳过全天。入口：放学面板第4项 → 全天路线第4项到第二页 → 第4项“同学、反应与和棋”。未满足的选项会显示缺少条件。详情见 `结局攻略_含剧透.md`。

旧12结局、v3.0的20结局收集成就维持原门槛，新设23结局全档案，不会因更新撤销已获成就。神级依旧是180秒有效游玩的必败闭环，所有新非失败出口同样封锁；六格成就只要求完成挑战，不要求神级通关。

## 自动保存与升级

有效游戏时间每5秒、关键操作、页面隐藏／离开等事件会尝试自动保存。最近自动记录与安全检查点分开保存，Game Over不会覆盖安全重试点。主菜单继续、结局页最近检查点重试、手动存档和JSON导入导出都保留；系统还保留最近12个检查点、本节开头和放学分歧。

新增保存内容包括两种反应事件的当前阶段／剩余时间／误操作次数、数字排列／提示／步骤、两位同学的冷却与同次事件判定、完整棋局合法行棋历史、轮次与对手剩余思考时间。读档先暂停，继续后有2秒准备期，离线时间不扣。

**推荐升级流程：旧版“存档→导出备份” → 打开v3.1 → “存档→导入备份” → 继续。**

- v2.2未完成的静止事件保留剩余时间与容错；v2.3—v3.0未完成的数字“条件反射”转换成新版静止，仅迁移这道题时给完整时间。
- 旧快速隐藏事件转换为当前难度的新快速反应；旧记录ID对应的迁移数字排列固定，不靠重复导入换题。
- **五子棋局面不能继续作为国际象棋局面。** 旧棋局胜／负／和统计归入旧棋档案，新棋盘从标准初始局面开始；不把旧胜局计为国际象棋胜场。当前课程、属性、其他活动与已解锁成就／结局继续保留。
- 旧版没有发生过的新同学提醒、静止新成就与国际象棋行为，不补造次数。已到旧版放学／逃生的存档不会倒退课程。

自动保存不是云存档。突然断电、强制结束浏览器或存储被禁用时，只能恢复最后一次成功写入的记录；重要进度请额外导出JSON。

开发测试需要Node.js、Python、Playwright及Chromium；游戏本身不需要这些软件。

```bash
node tests/test_chess.cjs
python tests/test_v31.py
python tests/test_additional.py
```

测试中的浏览器路径默认为Linux `/usr/bin/chromium`，其他环境需在测试启动代码中修改该路径。测试钩子只在显式 `?test=1` 时开放，正常打开不暴露钩子。测试模式默认不保存档案；请不要把带测试参数的地址用于日常游玩。

主要源码模块：`SchoolChess`（棋规）、`chessSearchGenerator`（分片AI）、`createReflexChallenge`（静止）、`createRapidChallenge`（快速反应）、`allyWarning`（NPC事件）、`migrate31Snapshot`（兼容）、`TIMETABLE`／`ENDINGS`／`ACHIEVEMENTS`（内容）、`tick`（主循环）。

验证边界：浏览器自动通关代理知道答案并即时反应，不代表真人难度已校准。触屏为模拟而非真机。Firefox、Safari及真实浏览器关闭后重开的磁盘存档尚未验收，详见测试说明。
