# 高二（2）班：最後一節課
## v3.10 · 四語課堂

完整單文件網頁游戲。在 v3.9 的基礎上補全簡體中文、繁體中文、English、日本語文本與語音路由，並加入真實模式英語課自動英文。玩法、1,036條學科題（含75條56選一與參數變式）、48條結局、174項成就不增刪。

## 運行

直接用瀏覽器打開 `index.html`。所有游戲腳本、樣式、題庫、離線翻譯詞典和程序繪制場景都在這一個文件內，不需要安裝游戲依賴或聯網翻譯。電腦網頁為默認佈局；在設置中啓用“手機端模式”可改為手機重排界面。

全屏：右上角按鈕或 `Alt + Enter`。暫停：`Esc`。系統限制全屏時仍能在普通窗口游玩。

## 四種語言／文字選項

主菜單“語言 / Language”或設置中的“四語文本與語音”面板，選擇：

| 選項 | 文本 | 語音匹配 |
|---|---|---|
| 簡體中文 | 簡體中文 | `zh-CN` 普通話 |
| 繁體中文 | 繁體中文，含完整字形轉換及常見用語處理 | `zh-TW` 台灣華語優先 |
| English | 完整英文 | `en-US` 優先，也接受本機其他英語聲線 |
| 日本語 | 完整日文 | `ja-JP` 日語 |

本次不再使用“English核心版／舊劇情保留中文”的顯示方案。菜單、系統提示、課堂對白、人物介紹、題目、選項、解析、辦公室、考試記錄、歸家、教程、成就、結局和動態記錄都接入新詞典。

**英文學科中被考查的英文原句和單詞保留原文。** 例如選擇語法形式時，英文選項不會被翻譯掉；題目指令與解析隨語言切換。數值、化學式、數學符號、按鍵名、代碼標識符和題目答案位置也不被翻譯。語言選擇器保留語言本身的名稱，便於找回自己的語言。

四語共用同一個題池和規則，語言不再限制隨機抽題範圍。切換不會重抽題目、移動答案、重置倒計時、增加聽課時間或改變難度。對白先整體翻譯再逐字顯示，不對半句中文逐幀拼接翻譯。

## 語音

**對話語音默認關閉。** 在同一面板啓用“對話語音播報”。四張聲線狀態卡顯示本機可用情況，分別提供試聽。

語音使用瀏覽器提供、標記為本地服務的系統語音，不是預錄真人配音，也不訪問麥克風。電腦或手機缺少匹配語言的聲線時，會給出提示並保留完整文字；不會拿中文聲線代讀日文，也不會聯網下載聲線。需要相應的系統語音包才能實際聽到該語種。

播報跟隨實際顯示語言。暫停、切出頁面、換句、關閉語音或切換語言時停止舊隊列；不會累積多段對白。設備稍後提供聲線時，只嘗試恢復仍有效的當前請求，取消過的請求不會突然發聲。程今容保留較慢語速與停頓。

四語路由和播報文本經過模擬聲線測試；當前測試環境沒有真實中文、日文發音質量的聽測結果。不能把“接口接受請求”當作“每台設備都內置四種聲音”。

## 真實模式的英語課

真實模式在新開周目時固定。在真實模式下，進入英語課開場與正式課堂後，界面、對白、問題、選項提示和已開啓的語音臨時使用英文。普通模式的英語課仍按玩家所選顯示語言。

**自動英文不會改寫語言偏好，也不會自行開啓語音。** 英語課中修改語言設置，修改的是課後要恢復的語言；該節課仍保持英文。下課後、課間、辦公室、歸家、逃生與主菜單恢復偏好語言。真實模式存檔在英語課中讀檔時也保持此規則。

題目的英文考查材料本來就是英文，不受偏好語言影響。這與“真實模式整個英語課堂自動英文”是兩件不同的事。

## 原有模式與操作保留

學習模式仍默認關閉：休閒規則為少題、基礎題、短固定時限；學習規則為更多問題、分級預算及較慢課堂進度。六檔難度、七日與七晚、真實模式收繳、考試坐姿監考、國際象棋、體育三項目、同學攻略、鏡子、辦公室與DeepShawn封存試煉保持原規則。

`1—9` 選擇課桌動作；空格收好物品。數字快速反應中，鍵盤按目標按鈕的左起位置，觸屏點目標大數字。條件反射是松手靜止，不能與快速反應混用。魔方仍支持 `R → U → Shift+R → Shift+U` 或 `R → U → Q → E`。國際象棋支持點擊，以及方向鍵和Enter。

彭望梓與王梓銳仍為不同髮型和配飾的無貓尾造型。本次沒有增加或減少關係數值與路線條件。

## 舊存檔

升級前先在舊版導出JSON，在新版導入。原題目、選項、題目編號、剩餘時間、課表和游戲狀態保持原值；新增日文偏好可隨備份保存。舊版的語言值 `zh-CN`、`zh-TW`、`en` 繼續有效。

自動存檔、檢查點和本地記錄不是雲存檔。更換瀏覽器、清除數據或移動本地HTML後，建議用JSON備份遷移。真實模式收繳仍不會因普通檢查點讀檔而撤銷。

## 文件與構建

- `index.html`：全部可運行代碼與內容。
- `locales/translations.tsv`：4,439組源文本家族的英文、日文譯文，`=`表示使用該家族已經提供的英文；動態參數佔位符必須保留。
- `locales/families.json`、`source_catalog.json`、`extra.json`：源家族、提取目錄和界面補充翻譯。
- `locales/en.json`、`ja.json`、`zh-TW.json`：構建出的完整文本條目；動態模板同時在內嵌目錄中。
- `tools/locale310.js`、`locale310.css`：本地化、語音、課堂語言切換及佈局。
- `tools/build.py`：從保留的v3.9基線構建同一游戲。
- `tests/`：回歸測試、聲線模擬、佈局檢查與結果。

構建需要 Python 3、BeautifulSoup4 和 ICU `uconv`；命令為 `python tools/build.py`。構建不請求外部翻譯服務，普通玩家不需要這些工具。測試需要 Python Playwright 與 Chromium，環境變量 `CHROMIUM_BIN` 可指定瀏覽器路徑。

實際驗證範圍、通過數量和未驗收項目以《測試說明.txt》為準。譯文已進行技術完整性與佔位符檢查，但沒有經過母語編輯與高中教師聯合逐題審校；題庫包含變式，不代表1,036個不同知識點。
