# 高二（2）班：最后一节课 · v3.21「旧楼异相」

本版在实际 v3.20「路线与迷踪」源码上更新**独立的旧楼五夜**：重做菜单、监控室、四路监控、控制台、说明、设置、档案、暂停和结算界面；增加独立诡异画风、可关闭的闪屏突脸与氛围声音。

校园与归家、九图五玩法捉迷藏、海胆苹果经典五波、扩展战术对战均保留。没有用新模式替代旧模式，没有修改五夜敌人逻辑、七档难度、150秒每夜、五夜流程、耗电数值、12枚原勋章或5条原结局的条件。

## 运行与进入

直接用浏览器打开 `index.html`。运行代码、图形和音效生成代码都在该文件中，没有新的外部网络资源或游戏运行依赖。

主菜单 → 独立游戏 → 勾选五夜守夜模式 → 旧楼五夜。

五夜的启动开关沿用旧记录；新浏览器中仍默认关闭。进入后可以选择难度、开新局，或继续原五夜进度。全屏按钮与 `Alt + Enter` 保留。

## 独立画风与惊吓设置

进入旧楼五夜后，点击顶部 **「五夜画面与惊吓」**。准备页也直接显示「诡异画风」开关。

| 设置 | 新浏览器默认 | 作用 |
|---|---|---|
| 诡异画风 | **关闭** | 只在五夜切换三种来客、所有夜巡场景和菜单界面为另一套画风。 |
| 失守突脸 | 开启 | 新发生的失败后播放一次约1.2秒的近距离来客画面。 |
| 短促闪屏 | 开启 | 突脸中叠加一次低亮度脉冲，不连续频闪；还受游戏总闪烁开关限制。 |
| 氛围画面与音效 | 开启 | 监控扫描纹、缓慢光照变化、有限的短音效；不额外耗电。 |
| 画面档位 | 均衡 | 省电20、均衡30、流畅60次/秒绘制上限；实际速度取决于设备。 |

诡异画风不强制打开闪屏，不提高敌人速度，不改变抽签结果、奖励或计时。关闭后恢复正常画风。进入其他模式时不继承五夜主题。

突脸可以按 `Esc`、`Enter`、空格或点「跳过」立即结束。它发生在失败已结算之后，跳过不会撤销失败；从失败存档恢复不会再次播放。预览需要主动确认，不增加失败、重试、勋章或结局。

启用系统「减少动态效果」时采用静态近景并关闭闪动与移动效果。可单独关闭突脸、闪屏或氛围声音。音效服从全局音量，不会自己提高主音量。

## 存档与升级

升级前，在旧版对应模式中分别导出 JSON 备份。新版在相同模式中导入。

五夜沿用原 `lastclass-independent317` 备份格式，原进度、夜次、电量、开关、敌人和随机状态不重置。继续后先暂停，手动继续保留2秒准备。只有失败原因增加了可选显示字段，旧记录没有它也能打开。

**五夜画风、惊吓和画面档位是浏览器偏好，不包含在五夜进度 JSON 中。** 它们单独保存到 `last-class-night-visuals-v321`，新浏览器或清除该项后，诡异画风恢复默认关闭。校园、独立对战、捉迷藏的设置与存档键没有被替换。

直接移动本地 HTML 或换浏览器不保证共享原本地记录，请使用 JSON 导出／导入迁移。此次本地文件原生重启测试被运行环境拦截，不能当作已经验证磁盘持久保存。

## 构建

运行游戏不需要构建。修改源模块后，可以从本目录运行：

```sh
python tools/build.py
```

只需要 Python 3 标准库。构建脚本保留精确的 v3.20 基底，在固定锚点加入 `tools/night321.js`、`tools/night321.css` 和八语新增文本，生成单一 `index.html`。重复构建具有相同的 SHA-256。

| 文件 | 用途 |
|---|---|
| `index.html` | 完整可玩版本 |
| `tools/base_v3_20.html` | 原版本精确构建基底 |
| `tools/night321.js` | 夜巡绘制、设置、音效与惊吓 |
| `tools/night321.css` | 只作用于五夜根节点的样式 |
| `tools/locales321.js` | 本版新增八语文本 |
| `tools/hooks321.js` | 仅 URL 带 `?test=1` 时开放的测试接口 |
| `tests/` | 自动检查脚本和实际报告，不是运行依赖 |

测试需额外安装 Python Playwright 和 Chromium。当前测试脚本默认使用 `/usr/bin/chromium`；在其他系统上应修改测试脚本的浏览器路径。自动通关代理能读取游戏状态，不能作为真人难度标尺。

## 范围与限制

本版没有增加新的五夜规则、结局或勋章，没有重新翻译旧版全量文本。本次新增界面文本提供八语版本；历史内容的翻译范围沿用原版。

人物和房间采用程序绘制与缓存，不是外部录制视频或真人照片。详细性能原始数据和不利结果见《性能说明.md》；复杂的新画面不代表总CPU消耗一定低于旧版。手机真机、Safari、Firefox、长时间发热、真实声线与完整校园七日的新一轮验收未完成。
