# 《高二（2）班：最后一节课》

> 单 HTML 网页恐怖潜行 Galgame 游戏开发策划案



## 1. 项目定位


游戏类型：
- 校园恐怖
- 潜行
- Galgame 对话
- 反应游戏
- 资源管理
- 多结局
- 第一人称课桌视角

运行形式：
- 单个 index.html
- 不使用后端
- 不使用数据库
- 不依赖框架
- 不依赖 CDN
- HTML + CSS + JavaScript 全部写在一个文件中
- PC 浏览器优先
- 手机端可以运行，但不是主要操作平台

推荐游戏时长：
- 单局 20～35 分钟
- 快速模式 10～15 分钟

核心目标：
玩家扮演高二（2）班学生。
在一天六节课中偷偷进行：
- 玩魔方
- 写其他作业
- 玩手机
- 查看消息

同时避免被任课老师、班主任以及巡查人员发现。
只要坚持到真正放学，并成功离开教学楼，就视为通关。


## 2. 世界观设定


游戏发生在一所名为：
「江城大学附属中学」
的架空高中。

玩家所在班级：
高二（2）班

时间：
星期一，07:40。

当天看似和平时完全一样。

但玩家逐渐发现：
- 老师有时会同时出现在教室和走廊
- 后门玻璃上偶尔会出现人影
- 广播内容开始发生异常
- 教室时钟偶尔倒退
- 同学似乎逐渐失去反应
- 每一次下课铃，都不一定是真的

玩家唯一能够确定的是：
必须熬到真正的17:30。


## 3. 游戏核心理念


整个游戏围绕一句话设计：

「你不知道老师什么时候会看你。」

游戏恐怖感不要主要依赖突然贴脸。
而应该依赖：
- 脚步声
- 后门玻璃
- 老师突然停止讲课
- 全班瞬间安静
- 鼠标移动时出现视线
- 门把手转动
- 教室灯轻微闪烁
- 假下课
- 突然点名
- 没有提示的巡视

核心心理压力来自：
玩家正在做违规行为，但不知道危险什么时候出现。

## 6. 核心属性


一、suspicion 怀疑值
范围：0～100

0～29：正常
30～49：老师开始注意玩家
50～69：巡逻概率增加
70～89：随机检查概率大幅增加
90～99：危险状态
100：被发现

二、focus 专注值
范围：0～100

专注越低：
- 屏幕越模糊
- 老师位置越难判断
- 后门幻觉概率越高
- 回答问题时间越短
- UI可能短暂错位

恢复方式：
- 听课 +8
- 玩魔方 +15
- 休息 +10

三、boredom 无聊值
范围：0～100

一直听课会增加无聊值。
无聊过高会降低专注，因此不能一直选择最安全行为。

四、phoneRisk 手机风险值
连续使用手机时间越长，风险越高：
3秒：小风险
6秒：中风险
10秒：高风险
15秒：极高风险


## 7. 五种核心行为


1）听课
风险最低
效果：
- 怀疑值 -3
- 专注值 +5
- 无聊值 +5

2）写其他作业
风险中低
增加 homeworkProgress
老师靠近时必须切回本科课本。

3）玩魔方
风险中等
通过 U / R / F / L / D / B 模拟转动。
不需要真实完整模拟三阶魔方。
可通过完成公式：
R U R' U'
增加进度。
成功后：
- 专注 +15
- 魔方进度 +1

4）玩手机
高风险
手机覆盖桌面区域。

APP：
- 聊天
- 短视频
- 游戏
- 时间

聊天可获得老师巡逻提示。
例如：
同桌：“后门！！”

手机中的时间是后期判断真假放学铃的重要依据。

5）观察
可以观察：
- 讲台
- 老师
- 后门
- 窗外
- 同桌

观察会消耗时间，但能提前发现危险。


## 8. 紧急隐藏系统


老师突然靠近时，画面出现“！！”。

玩家必须快速完成：
关闭手机
→ 收起魔方
→ 拿笔
→ 点击课本

可以简化成三个按钮：
[藏起来]
[拿笔]
[看书]

限时：
普通老师：2秒
班主任：1.5秒
最终阶段：1秒

失败：
怀疑值大幅增加。


## 9. 老师巡逻系统


每位老师拥有独立巡逻 AI。

教师状态示例：

teacherState = {
position,
targetPosition,
speed,
awareness,
patrolMode
}

位置简化为：
- 讲台
- 第一排
- 第二排
- 第三排
- 玩家左侧
- 玩家右侧
- 后排
- 门口

不需要复杂寻路。
使用 CSS transform/transition 动画即可。


## 10. 后门系统


右上角始终存在“后门玻璃”。

可能随机出现：
- 黑影
- 半张脸
- 眼镜反光
- 手
- 一双眼睛
- 什么都没有

出现时不一定有声音。

如果巡查人员正在后门观察，而玩家在用手机：
怀疑值会快速上升。

## 17. 数学Boss阶段


第一阶段：函数巡视
老师移动路线完全随机，速度会突然变化。

第二阶段：死亡点名
老师突然点名。
例如：
f(x)=x²
f'(2)=？

选项：
2 / 4 / 6 / 8

答题同时，后门可能出现巡查身影。

第三阶段：1/56
屏幕出现56个数字/按钮。
只有一个正确。

如果此前听课时间较长，正确按钮短暂闪烁。
如果一直玩手机，则无提示。

第四阶段：假下课
铃声响起。

下课了。
是否离开？

[继续坐着]
