> 17:30 以前，不要相信任何一次下课铃。

**v2.2 — 六档难度、36 项成就、条件反射与平衡更新**

单文件 HTML 校园恐怖潜行游戏。保留六节课程、教师巡逻、后门检查、Galgame 对话、数学 Boss、最终逃生、12 个结局、传纸条、睡觉、全屏、自动保存和检查点重试。本次直接更新完整游戏，不需要与旧文件拼接。

## 1. 运行与升级

解压后，用桌面浏览器打开 `index.html`。主菜单先选择难度，再开始标准流程或快速流程；有中途记录时可选择继续游戏。右上角“全屏”或 `Alt + Enter` 切换全屏，退出全屏会自动暂停。

**升级保留进度：先在 v2.0／v2.1 中“存档 → 导出备份”，再在 v2.2 中“存档 → 导入备份 → 继续”。** 请保留旧文件与 JSON 备份，不要先清除浏览器数据。

旧进度会自动补齐为 **普通难度**，保留课程、题目、对话、资源、纸条、睡眠与检查点。旧结局会补发对应结局成就；旧记录没有保存过的隐藏成功次数等，不会凭空推算。已经开始的旧版静止事件保留已消耗时间，补充新容错；下一次触发使用新参数。v2.2 存档不保证能交给旧版游戏反向读取。

直接以本地文件运行时，请在移动文件、改文件名、清理数据、更换浏览器前导出备份。不同运行位置下的本地记录不要视为同一份；找不到继续入口时可导入 JSON。

电脑已经安装 Python 3 时，也可在游戏目录启动可选静态服务：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器地址：

```text
http://127.0.0.1:8000/
```

静态服务不增加账号、云存档或游戏后端。切换地址前仍应导出备份。本次自动测试环境未开放本地导航，静态服务地址的真实磁盘持久化未验收。

## 2. 六档难度

**标准／快速决定课时，简单／普通／困难／地狱／极限／神级决定规则。** 两者独立。难度在新周目开始时固定，并写入全部检查点。设置中修改的是下一局选择，不会降低当前周目的难度。

标准流程前五节各 180 秒、数学课 240 秒；快速流程六节各 90 秒。这是自由课堂计时，剧情、挑战和逃生的耗时另计，不是承诺的整局用时。

| 难度 | 怀疑增长倍率 | 巡逻速度倍率 | 普通巡视隐藏时间* | 定位 |
| --- | ---: | ---: | ---: | --- |
| 简单 | 0.65 | 0.80 | 3.60 秒 | 反应窗口更长、资源恢复更多 |
| 普通 | 1.00 | 1.00 | 2.40 秒 | 调整后的基准规则 |
| 困难 | 1.22 | 1.14 | 2.11 秒 | 巡逻加快，失误代价增加 |
| 地狱 | 1.50 | 1.28 | 1.82 秒 | 恢复更少，逃生压力更大 |
| 极限 | 1.80 | 1.45 | 1.54 秒 | 仍有正常通关路线，操作窗口短 |
| 神级 | 2.25 | 1.68 | 1.32 秒 | **不可通关的生存挑战** |

\* 非教学、非数学、无英语强化时的基础窗口，显示值四舍五入；数学基础窗口更短，英语强化再缩短 15%。答题、巡逻间隔、随机事件间隔、逃生消耗、恢复收益和冲刺要求也随难度变化。全部参数见 [平衡性调整](./平衡性调整.md)。

### 神级不是隐藏的通关谜题

神级会在开局确认、难度面板与游戏 HUD 明示“无法通关”。课堂及逃生中的**有效游玩时间累计达到 180 秒，必定进入“神级闭环”失败**；150 秒时提醒最后 30 秒。课堂／逃生的挑战计时计入，暂停、阻塞剧情、离线、课间总结和读档准备不计。

所有非失败出口都被封锁，包括正常离校、魔方出口、无人注意路线、交卷、同行、玻璃出口，以及接过钥匙成为守门人。试图进入这些结局会转为神级闭环，不会解锁被封锁的结局、增加成功通关次数或颁发毕业证。普通坏结局仍可发生。

可自动保存、从检查点重试、记录最好成绩，并获得坚持 **60／120／180 秒**的成就。恢复检查点也恢复该点已消耗的神级时间，不会自动清零。没有要求玩家完成“神级通关”的不可能成就。

这是游戏规则层面的确定性封锁，不是防修改或联网防作弊系统。修改本地源码当然可以改变规则。

## 3. 条件反射削弱

普通难度从 v2.1 的“0.8 秒准备、静止 2 秒、一次有效输入直接失败”，调整为：

**1.4 秒准备 → 静止 1.4 秒 → 允许一次有效误操作。**

第一次明显动作只消耗容错，给出 0.35 秒重新松手的缓冲，再重新完成完整静止时长；容错耗尽后再次明显操作才失败。界面显示准备／静止阶段、剩余时间、剩余容错和提示，不是继续操作也能过关。

松开键盘、松开鼠标／触摸、键盘长按自动重复、轻微指针抖动、输入法组合、系统快捷键不会直接计为失败。指针移动采用累计距离阈值，明显拖动仍会被检测。暂停、手记、静音等系统操作不作为违规输入；恢复时不会因指针重定位直接失败。

| 难度 | 准备 | 保持静止 | 可容错次数 |
| --- | ---: | ---: | ---: |
| 简单 | 1.80 秒 | 1.10 秒 | 2 |
| 普通 | 1.40 秒 | 1.40 秒 | 1 |
| 困难 | 1.30 秒 | 1.50 秒 | 1 |
| 地狱 | 1.15 秒 | 1.65 秒 | 1 |
| 极限 | 1.00 秒 | 1.80 秒 | 1 |
| 神级 | 1.00 秒 | 1.80 秒 | 1 |

课堂失败的基础怀疑惩罚从 **17 降为 8**，再应用所选难度倍率；成功基础奖励调整为怀疑 −2、专注 +3。简单与普通的生物课保留一次固定反射，取消操作频率额外触发。困难及以上保留两次固定反射，过密操作的额外触发每节最多一次，且有 75 秒冷却。

最终逃生的生物回忆也使用新容错，失败基础追赶惩罚从 20 降为 10。物理回忆仍需等待 3 秒，不等同于生物条件反射。

## 4. 成就档案

右上角“成就”在主菜单、游戏和结局页面均可使用，支持“全部／已解锁／未解锁／课堂／挑战／结局”筛选、进度显示和解锁时间。

共 **36 项**：课堂 12 项、挑战 11 项、结局 13 项。包含正式隐藏、零失误反射、回条、实际睡眠时长、魔方、作业、六条线索、答题、五档毕业证、快速通关、无手机通关、神级生存，以及 12 个结局和全结局收集。

已解锁成就跨周目保留，随 JSON 备份导入导出；回读检查点不会撤销成就。同一段记录反复回档，不会被当作额外成功次数累加。需要“一个周目”达成的条件不能跨局拼凑；进度条展示历史最高单局进度，并同时显示当前记录。

五档毕业证分别要求在对应难度成功离校，高难度证书不自动替代低难度证书。成就不提供属性加成。“干净的课本”检查恢复后的本次记录线，允许检查点重试，不是零读档铁人模式。神级没有毕业证。

旧版结局按档案补发对应成就；缺失历史统计的其他成就需继续游玩。未发现的结局成就默认隐藏名称，可通过设置开启线索。完整条件见 [成就说明](./成就说明.md)，其中结局名单放在折叠区域。

快速流程的作业效率按总课堂时长比例 `1140 / 540` 补偿。盯同一个观察目标超过 8 秒后会缓慢增加无聊，不再靠同一观察点无限降低无聊。更多实现细节与全部数值见 [平衡性调整](./平衡性调整.md)。

## 7. 自动保存与检查点

约每 **5 秒有效游戏时间**自动记录，关键操作、剧情转场也保存。页面隐藏、失焦及离开页面事件触发时尝试立即保存并暂停。继续后先显示确认，再给 2 秒恢复缓冲；离线时间不补扣。

自动记录和安全检查点分开。六档难度、标准与快速流程都可在 Game Over 后选择“从最近检查点重新出发”。保留最近 12 个检查点，另保留本节开头、放学分歧与手动存档；失败页不会覆盖安全检查点。难度、神级计时、反射容错、热度、疲劳、纸条、睡眠和成就统计均参与保存。

| 存储键 | 内容 |
| --- | --- |
| `last-class.offline.v1` | 结局、成就、设置、最好成绩、手机限制 |
| `last-class.progress.v2` | 当前周目、中途记录、检查点 |
| `last-class.progress.v2.backup` | 进度备份 |

沿用旧版存储键与外层版本 2，玩法状态增加 `balanceVersion: 2`，原 `mechanicsVersion: 1` 保留。导入会校验新字段与检查点的一致性，不合法难度或损坏数据会被拒绝。校验不是加密或防作弊。

**本地保存不是云存档，也不保证任何中断都零丢失。** 突然断电、强制结束、浏览器拒绝存储时，最多只能恢复最近一次成功写入的记录。看到存储警告应先导出 JSON。多标签页冲突时会停止覆盖并提示处理，建议同一份记录只开一个游戏标签页。

## 9. 验证与已知限制

本次实际结果：**123／123 项自动检查通过**，其中原系统 31 项、v2.1 回归 38 项、v2.2 专项 54 项；另通过 JavaScript 语法检查，测试期间未捕获到 JavaScript 运行时异常。

大部分集成测试使用可控时钟与模拟 localStorage；中断恢复通过重建页面和重新注入记录验证。**没有完成真实关闭浏览器后重新打开的磁盘持久化测试**，也没有测试 Safari、Firefox、手机真机或所有实体输入法。自动通关代理知道正确答案并能即时反应，因此只证明指定测试路径可走通，不代表人类玩家的难度、通关率或数值平衡已全面校准。详细用例和限制见 [测试说明](./测试说明.txt)。
