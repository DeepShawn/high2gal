# 高二（2）班：最后一节课
## v3.12 · 课时与节奏

单文件校园潜行／恐怖剧情游戏。`index.html` 包含运行所需的 HTML、CSS 和 JavaScript，不需要后端、游戏框架、外部图片、CDN 或安装游戏依赖。本版从用户提供的 v3.11 源码修改，保留原有玩法与四语内容。

## 运行

用桌面浏览器打开 `index.html`。完整 ZIP 解压后也只需打开此文件，不需要运行构建脚本。电脑布局默认启用；手机请进入「设置 → 画面与手机布局 → 手机端模式」。全屏使用界面按钮或 `Alt + Enter`；浏览器可能限制全屏及本地文件存储。

新玩家从主菜单「新手教程」开始。教程新增「课时、卫生与设置」章节，总计19章；练习与正式周目分离。

## 本版六项变更

### 1. 清理垃圾只在中午和晚上

上午、下午不再产生卫生任务，包括原有校长事件发起的日间检查。每天中午、晚上各至多一次，且必须人在教室；在食堂、操场、走廊或办公室时不会要求远程整理。用餐时离开教室，可以在后续午休／晚自习中遇到对应时段的检查。

老师宣布后才出现清纸屑、整理课本、清扫桌下三项任务。未完成仍会被老师帮忙整理，可能发现手机。三项完成后按钮撤下。这里没有增加平时可反复刷收益的清理按钮。

### 2. 设置页不再持续闪烁

设置页改为独立稳定面板，停止背景界面逐帧重绘，并隔离恐怖动画和滤镜。调音量、输入倍率、展开分区不需要反复重建整页。手机设置采用内部滚动，顶部关闭按钮常驻；返回游戏继续保留原有恢复缓冲。

### 3. 非真实模式最高L2

本周目未开启真实模式时，所有出题入口只选择真正的 L1／L2 题目，包含：课堂提问、正式考试、普通数学、56选一、逃生回忆与路线、反光镜试炼、DeepShawn封存试炼。不开例外，也不把原有L3／L4题改标签伪装成L2。

开启学习模式也不突破这一上限。学习模式依旧决定题量、短时／分级计时和课堂时钟；真实模式与学习模式是两个独立开关。

真实模式和学习模式仍在开局时固定，设置开关影响下一周目。已在真实模式中的记录不会因修改「下一局」设置而变更当前规则。新开的非真实模式或导入的旧非真实记录才按L2上限执行。

完整题库没有删题：仍为1,036条学科题（961条四选一＋75条56选一），另有6条路线阅读。真实学习模式可以使用高等级题；真实模式的指定高等级试炼保留。

### 4. 攻略入口折叠进设置

日常游戏面板与主菜单不再放置「攻略／同学」「攻略人物」快捷按钮；日常校园事务不直接显示情书与好感对话。

统一入口：**设置 → 展开「02 · 攻略与同学互动」**。可以在这里开启班长／体委路线、查看关系、进入互动。该区默认折叠，两条感情路线依旧默认关闭。基础同学姓名牌、状态、提醒与普通友方功能不删除。

在设置里选定互动后会返回正式场景执行，并受当前课堂纪律约束。正式考试、晨交、罚站、阻塞剧情及挑战期间不能借设置绕过行动限制。攻略结局选择仍保留。

### 5. 两端难度重新平衡

简单、普通小幅降低怀疑增长和巡走压力，改善恢复及逃生资源；困难基础参数不变；地狱、极限、神级提高压力并降低部分收益。答题倍率同步调整，但不会叠乘两次。

具体值见 `平衡性调整.md`。两种反应题的独立基础配置、镜子取出／冷却、归家窗口和神级180秒规则没有因课时倍率而改变。

### 6. 所有课堂四倍延长，可自定义流速

所有学科课、体育课、两节晚自习的基础课时均为 v3.11 的4倍。到校、课间、午晚餐、午休、办公室对话、归家和逃生不做4倍延长。

设置 → 课时与规则 → **课堂时间流速**：范围0.25～4，默认1；提供0.5／1／2／4快捷按钮。数值越大，课堂进度越快。正在进行的周目可立即修改，保留已过进度，存档与下一天沿用。

```text
实际自由课堂时长 = v3.11原课时 × 4 ÷ 自定义倍率 ÷ 学习时钟倍率
学习时钟倍率：休闲1；学习0.65
```

例如旧版标准学科课150秒：新版默认为600秒；自定义×2为300秒；×4回到150秒。开启学习模式且自定义×1时约923秒，另加暂停、剧情和挑战占用时间。

自定义倍率只改变课时进度，不加速或减速答题、数字快反、静止挑战、镜子取出、手机使用、父母检查、教师巡视、后门随机周期与神级有效生存计时。不会把4秒反应窗口误变成16秒。

## 常用操作

| 操作 | 键盘 |
|---|---|
| 听课／作业／魔方／手机／观察 | 1—5 |
| 纸条／睡觉／国际象棋／讲话 | 6—9 |
| 收好／分步快速隐藏 | 空格；需要逐次操作 |
| 魔方 | R、U、Shift+R、Shift+U，或R、U、Q、E |
| 国际象棋 | 方向键、Enter；也可点击棋子和落点 |
| 继续对白 | Enter |
| 暂停 | Esc |
| 全屏 | Alt + Enter 或按钮 |

数字快速反应：触屏点提示的目标大数字；键盘按该按钮从左向右的位置键。生物条件反射则相反：准备后松手、保持静止。详细说明及实际练习见游戏内教程。

## 升级与存档

1. 在旧版「存档」导出JSON备份。
2. 打开新版，导入备份，继续游戏。
3. 检查设置中的本周目规则和课堂时间流速。

旧课堂／体育中途记录按已过比例迁移到四倍课时，例如原来25%进度仍为25%，不会返回开课。只迁移一次，重复读档不再乘4。

旧非真实模式正在回答的L3／L4题会换成同科真正的L1／L2题；旧总时限、剩余时间保持不变，旧答案提示会清除。新版本自行产生的题目与顺序照常保存。旧上午／下午尚未完成的卫生检查无罚取消，不冒领奖励。

本地存储不是云存档。清理浏览器数据、更换浏览器或移动文件可能影响记录，重要进度应导出JSON。突然断电时只能恢复最近一次成功写入的记录。
