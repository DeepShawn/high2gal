# 高二（2）班：最后一节课
## v3.9 · 同窗与球局

单 HTML 校园恐怖潜行／对话游戏。基于 v3.8 更新；现有 48 条结局档案、174 项成就、1,036 条学科题（961 四选一＋75 数学56选一，包含参数变式）。

## 运行与平台

打开 `index.html`。HTML、CSS、JavaScript、题库、程序绘制场景、程序音效都包含在此文件内；没有运行框架、CDN、外部图片或后端。电脑网页版是默认布局。

设置 → **手机端模式**：重排为手机原生字号、单列内容、固定底部动作网格、可滚动的题目／系统弹框，以及适配手机的场景预览。横竖屏均有规则；再次关闭恢复电脑16:9。它们是同一网页的两种布局，不是另外生成的 Android APK 或 iOS 应用。

全屏：`Alt + Enter` 或全屏按钮。浏览器拒绝全屏时不影响普通页面游玩。

## 语言

设置／主菜单 Language：简体中文、繁体中文、English · core。

中文两种字形用于整局文字显示。English 当前是**核心本地化版本，不是完整英文剧本**：核心按钮、18章教程讲解、新增人物互动与结局、体育选择和840条新题有英文；旧故事原句和部分旧系统长文保留中文，并标记中文原文。选择英语时，正常新抽题使用有英文的新增题；进行中的旧题不会重抽。

无在线翻译请求。切换语言、布局不会清空当前题目、改变答案顺序或延长剩余时间。对话语音仍默认关闭；系统没有对应语言的本地声线时仅显示文字。

## 学习模式，默认关闭

在主菜单或设置中勾选，**作用于下一局**。难度、标准／快速、学习开关是三个独立选择；进行中的周目使用存档内的规则。

| 项目 | 关闭：休闲 | 开启：学习 |
|---|---|---|
| 普通课堂口头题 | 每节最多一题，主要L1/L2 | 原学科事件＋每节四次额外提问 |
| 连堂考试 | 保留三题，优先基础题 | 保留三题，可抽全部等级 |
| 普通档口头题 | 固定12秒 | L1/2/3/4分别15/25/40/60秒 |
| 普通档笔试 | 固定14秒 | 等级时间＋3秒 |
| 普通档56选一 | 固定16秒 | 等级时间＋6秒 |
| 56选一数量 | 每次数学课3题；逃生末段3题 | 每次数学课5题；逃生末段5题 |
| 课堂时钟 | ×1 | ×0.65 |

以上题目预算最后只乘一次难度答题倍率，再保留0.1秒；快速课时不重复缩短。学习模式减慢的是**课堂进度时钟**，不是快速反应、答题、手机使用、睡眠或父母检查的实秒计时。神级180秒仍按有效实秒推进。

休闲不是取消全部考题：任务问答、连堂考试、订正和必须的逃生机关保留；DeepShawn封存试炼是主动接受的高难例外。

## 体育与人物

刘嗨任教。上课先选羽毛球、篮球、乒乓球，再选彭望梓／王梓锐／独自练习。每种项目有三段6秒练习，实际完成才结算，本节不能临时换项目。选择伙伴可得到关系收益；开启对应攻略并完成羽毛球，另加好感8、专注6。同一节只结算一次。

这是三个带独立选择和练习步骤的校园活动，不是另附的物理引擎球类竞技游戏。

王梓锐改为女体委、猫咪性格、短发与青绿色运动发带、星形发夹、口哨，无猫尾；彭望梓保留较长头发、紫藤蝶结发卡、猫耳和无尾造型。

主菜单／设置的“攻略人物”可分别启用两人，默认都关闭。友情不要求开关，情书和心意确认要求对应开关。游戏中的“攻略／同学”进入互动：完成一次4秒对话或5秒递信才计收益，每个话题每天一次。心意确认需自由时段、好感至少55及已送达一封信；可以只做朋友。课堂私聊和递信有真实风险。

DeepShawn是化学课代表，外号“女神”，在全部新手教程章节担任讲解员。普通教学与正式成就隔离。神级有极难封存结局，详细条件见含剧透攻略；该结局仍未逃出学校，不算神级毕业。

## 存档升级

先在旧版导出 JSON，再在新版导入。v3.8当前题保留答案、选项、总预算和剩余时间；旧周目迁移为学习规则，避免半途突然缩时。新开局才默认休闲。正在进行的旧体育项目保留实际进度，以篮球练习承接，后续体育课正常选择。

新状态保存：学习政策、数字题堆、连续编号题位置、体育项目／搭档／练习完成、跨日互动、双方确认、DeepShawn试炼步骤和失败登记。语言与手机布局保存在设置中。

自动保存和安全检查点分开；浏览器本地存储不是云存档。移动HTML、无痕窗口、清理数据可能使旧记录不可用；重要进度导出JSON。真实模式收缴与封存试炼失败在本地同周目的常规读档中保留，不承诺阻止直接篡改源码或备份。

## 交付文件与开发

`index.html` 是完整可运行源码；其余是文档、可编辑题库、构建材料和测试，不是游戏依赖。

`tools/build.py` 可根据保留的v3.8基线、扩展模块和题库重建同一HTML。`tools/generate_bank.py` 可重建新增题库。构建命令：`python tools/build.py`；普通游玩不需要Python。

测试需要Python Playwright与Chromium。安装测试依赖后运行 `python tests/test_v39.py` 等；可以用环境变量 `CHROMIUM_BIN` 指定浏览器。测试数量和未验证范围见《测试说明.txt》，不要把测试代理的即时作答当作真人难度结论。
