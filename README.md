# 高二（2）班：最后一节课
## v3.10 · 四语课堂

完整单文件网页游戏。在 v3.9 的基础上补全简体中文、繁體中文、English、日本語文本与语音路由，并加入真实模式英语课自动英文。玩法、1,036条学科题（含75条56选一与参数变式）、48条结局、174项成就不增删。

## 运行

直接用浏览器打开 `index.html`。所有游戏脚本、样式、题库、离线翻译词典和程序绘制场景都在这一个文件内，不需要安装游戏依赖或联网翻译。电脑网页为默认布局；在设置中启用“手机端模式”可改为手机重排界面。

全屏：右上角按钮或 `Alt + Enter`。暂停：`Esc`。系统限制全屏时仍能在普通窗口游玩。

## 四种语言／文字选项

主菜单“语言 / Language”或设置中的“四语文本与语音”面板，选择：

| 选项 | 文本 | 语音匹配 |
|---|---|---|
| 简体中文 | 简体中文 | `zh-CN` 普通话 |
| 繁體中文 | 繁体中文，含完整字形转换及常见用语处理 | `zh-TW` 台湾华语优先 |
| English | 完整英文 | `en-US` 优先，也接受本机其他英语声线 |
| 日本語 | 完整日文 | `ja-JP` 日语 |

本次不再使用“English核心版／旧剧情保留中文”的显示方案。菜单、系统提示、课堂对白、人物介绍、题目、选项、解析、办公室、考试记录、归家、教程、成就、结局和动态记录都接入新词典。

**英文学科中被考查的英文原句和单词保留原文。** 例如选择语法形式时，英文选项不会被翻译掉；题目指令与解析随语言切换。数值、化学式、数学符号、按键名、代码标识符和题目答案位置也不被翻译。语言选择器保留语言本身的名称，便于找回自己的语言。

四语共用同一个题池和规则，语言不再限制随机抽题范围。切换不会重抽题目、移动答案、重置倒计时、增加听课时间或改变难度。对白先整体翻译再逐字显示，不对半句中文逐帧拼接翻译。

## 语音

**对话语音默认关闭。** 在同一面板启用“对话语音播报”。四张声线状态卡显示本机可用情况，分别提供试听。

语音使用浏览器提供、标记为本地服务的系统语音，不是预录真人配音，也不访问麦克风。电脑或手机缺少匹配语言的声线时，会给出提示并保留完整文字；不会拿中文声线代读日文，也不会联网下载声线。需要相应的系统语音包才能实际听到该语种。

播报跟随实际显示语言。暂停、切出页面、换句、关闭语音或切换语言时停止旧队列；不会累积多段对白。设备稍后提供声线时，只尝试恢复仍有效的当前请求，取消过的请求不会突然发声。程今容保留较慢语速与停顿。

四语路由和播报文本经过模拟声线测试；当前测试环境没有真实中文、日文发音质量的听测结果。不能把“接口接受请求”当作“每台设备都内置四种声音”。

## 真实模式的英语课

真实模式在新开周目时固定。在真实模式下，进入英语课开场与正式课堂后，界面、对白、问题、选项提示和已开启的语音临时使用英文。普通模式的英语课仍按玩家所选显示语言。

**自动英文不会改写语言偏好，也不会自行开启语音。** 英语课中修改语言设置，修改的是课后要恢复的语言；该节课仍保持英文。下课后、课间、办公室、归家、逃生与主菜单恢复偏好语言。真实模式存档在英语课中读档时也保持此规则。

题目的英文考查材料本来就是英文，不受偏好语言影响。这与“真实模式整个英语课堂自动英文”是两件不同的事。

## 原有模式与操作保留

学习模式仍默认关闭：休闲规则为少题、基础题、短固定时限；学习规则为更多问题、分级预算及较慢课堂进度。六档难度、七日与七晚、真实模式收缴、考试坐姿监考、国际象棋、体育三项目、同学攻略、镜子、办公室与DeepShawn封存试炼保持原规则。

`1—9` 选择课桌动作；空格收好物品。数字快速反应中，键盘按目标按钮的左起位置，触屏点目标大数字。条件反射是松手静止，不能与快速反应混用。魔方仍支持 `R → U → Shift+R → Shift+U` 或 `R → U → Q → E`。国际象棋支持点击，以及方向键和Enter。

彭望梓与王梓锐仍为不同发型和配饰的无猫尾造型。本次没有增加或减少关系数值与路线条件。

## 旧存档

升级前先在旧版导出JSON，在新版导入。原题目、选项、题目编号、剩余时间、课表和游戏状态保持原值；新增日文偏好可随备份保存。旧版的语言值 `zh-CN`、`zh-TW`、`en` 继续有效。

自动存档、检查点和本地记录不是云存档。更换浏览器、清除数据或移动本地HTML后，建议用JSON备份迁移。真实模式收缴仍不会因普通检查点读档而撤销。

## 文件与构建

- `index.html`：全部可运行代码与内容。
- `locales/translations.tsv`：4,439组源文本家族的英文、日文译文，`=`表示使用该家族已经提供的英文；动态参数占位符必须保留。
- `locales/families.json`、`source_catalog.json`、`extra.json`：源家族、提取目录和界面补充翻译。
- `locales/en.json`、`ja.json`、`zh-TW.json`：构建出的完整文本条目；动态模板同时在内嵌目录中。
- `tools/locale310.js`、`locale310.css`：本地化、语音、课堂语言切换及布局。
- `tools/build.py`：从保留的v3.9基线构建同一游戏。
- `tests/`：回归测试、声线模拟、布局检查与结果。

构建需要 Python 3、BeautifulSoup4 和 ICU `uconv`；命令为 `python tools/build.py`。构建不请求外部翻译服务，普通玩家不需要这些工具。测试需要 Python Playwright 与 Chromium，环境变量 `CHROMIUM_BIN` 可指定浏览器路径。

实际验证范围、通过数量和未验收项目以《测试说明.txt》为准。译文已进行技术完整性与占位符检查，但没有经过母语编辑与高中教师联合逐题审校；题库包含变式，不代表1,036个不同知识点。
