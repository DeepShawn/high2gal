# 高二（2）班：最后一节课
## v3.4 · 课间的回声

校园恐怖、潜行、对话、反应与资源管理游戏。**32 个结局、124 项成就**。在 v3.3 的实际源码上扩展，而不是另做一份互不兼容的演示。

## 运行

直接用浏览器打开同目录的 `index.html`。HTML、CSS、JavaScript、国际象棋引擎、场景与程序音效全部内嵌；无外部图片、音频、框架、CDN、联网接口或运行依赖。测试脚本需要额外的开发工具，但玩游戏不需要。

右上角 **全屏** 或 **Alt + Enter** 切换全屏。浏览器拒绝全屏时会提示，游戏仍可运行；退出全屏会暂停。手机横屏更适合完整教室视图，新增事务弹框与快速反应按钮单独放大，不随整个教室缩成小按钮。

## 模式与课表

主菜单可选单日、一周和归家；标准／快速决定课时，六档难度决定规则。神级仍为明确不可通关的生存挑战，没有通过新增支线绕开的成功出口。

一周指虚构校园的**星期一至星期日，共七天**。每天 07:20 到校，上午 5 节、下午 4 节、晚上 2 节晚自习，21:40 放学后进入归家。成功完成当晚才能日结并继续次日，周日也有归家。

每日九节日间课程中，六门核心学科至少各一次；体育 0—1 节，计入九节而非另加。可两节同科连堂，不会三连堂。开局固定全周课表，读档不会重新排课。课表键 **T**。

| 日程 | 游戏钟时间 |
|---|---|
| 到校／全周晨检 | 07:20—07:30 |
| 上午五节 | 07:30、08:25、09:20、10:15、11:10 开始，每节45分钟 |
| 午餐／午休 | 11:55—12:40；12:40—13:40 |
| 下午四节 | 13:40、14:35、15:30、16:25 开始，每节45分钟 |

以上是游戏钟，不需要按现实时间等待。新增真实课间、互动、提问、订正与测试会延长游玩过程。

**条件反射仍是 v2.2 的松手静止，不是数字题。** 普通难度准备1.4秒，静止1.4秒，一次明显误操作容错；物理的静候也保留。

**快速反应**：简单2次空格、普通3次空格；困难／地狱／极限／神级为3／4／5／6个数字。数字题触屏点击按钮上的目标数字，键盘按目标按钮的左起位置。下方顺序始终可见，长按不算多次操作。失败的学校基础怀疑恢复为一般课堂 +36、数学 +48，再乘难度等修正。

## v3.4 新玩法

### 课前广播、课间与测试

每次上课前先播报“下节课是某某课，由某某老师任教。”体育也播报。每节核心学科新增三次提问机会，和原课程事件排队执行，不在同一个弹框上叠题。

同科连堂第二节增加三题课堂测试；至少答对两题合格。各节仍独立计时，不合并为一节长课。相邻课堂／体育之间增加可玩的课间：标准24秒、快速12秒，至少停留5秒后可提前结束；不会在已有午餐、午休间再硬塞重复课间。

### 全周晨检：补写、抄写、收本、发本

全周每天到校后，标准50秒／快速28秒的收本前窗口里只出现**补作业与抄作业**。其余课桌动作隐藏且快捷键也不能穿透。暂停、设置和存档仍可用。

补写较慢但没有雷同风险；抄写更快，收取时可能发现相同错误。抄写抽签在进入晨检时保存，刷新不会重抽。到时先检查、提交并收齐本子，再选择领回／帮忙发回批改本，不是只改变一个百分比。被发现抄写要求本人订正，不无提示结束整周。

### 化学订正、重复回应与办公室

李芳林在化学课前检查三处订正。每处需4秒；晨间自己完整补写可以提前消除一处。提交未订正的作业会扣本，下一次下课进入**化学办公室**，说明错因、订正并领回后回到原日程。旧郭老师办公室路线保留。

化学提问有时需要对正确答案逐次回应2—3次；弹框明确显示已回应次数，额外给少量时间。不是按钮故障，也不会把一次长按当多次回答。答错或超时罚站**300秒有效校园时间**，期间不能做自己的娱乐活动。听课、观察、答题、教师要求的卫生、暂停、存档仍可使用；可跨课程和次日保存，归家、剧情、暂停及离线不抵扣。完整站满才解锁隐藏成就。

### 卫生检查与塑料玩具

仅当老师宣布检查，才出现三项“做卫生”按钮：清纸屑、整理课本、清扫桌下，每项2.2秒。必须全做完；只做两项仍不合格。超时后老师会实际靠近并代整理，有机会发现手机。固定讲台的教师也会在这项明确事件中走下来。检查结束，清理按钮撤下。

V菜单增加**玩具刀**，明确为圆钝、无刃的塑料道具，没有攻击或伤害功能。课堂摆弄仍有风险，被注意后有说明与暂存对话。郭自朝的手机／玩具台词含用户指定的粗口，是虚构角色台词，不是现实人物引述或物品鉴定。

### 三位友方同学

王子睿和李思聪会在留意周围、认真听讲、睡眠之间切换，状态显示在姓名卡。睡着都不提醒；李思聪听讲时不侦查，王子睿听讲也暂不望风，并有机会带动你听课。若老师发现他们睡着，会重点留意这一排22秒，提高后门关注，但不直接给玩家记一次被抓。

**彭王梓**是女班长，猫系性格，戴猫耳发卡，喜欢羽毛球；友好、护食，也会想抢一口别人的点心。自习课在讲台。默认提供帮助和羽毛球友情互动，不需要开启感情支线。

设置中的 **攻略 → 攻略彭王梓** 默认关闭。开启后，V菜单增加情书与四类对话。成功送达才加进度，话题与送信每天不能反复刷收益；课堂递信／私聊仍可能被老师叫住询问关系。可以保留隐私、说明只是朋友，不强制承认恋爱。支线为校园日常好感交流，不含性内容。

### 一周增压与归家多步隐藏

起始难度锁定，校园数值按日平滑向下一档靠近，最后一天不超过下一档；毕业证仍按起始档发放。极限周可以提高到神级的部分数值上限，但**不会自动开启神级必败闭环**。只有主动选择神级才有不可通关规则。

归家隐藏和学校快反使用同一套输入：先熄屏、藏手机，再完成装睡，**必须全部步骤完成才安全**。简单2次空格、普通3次，其他档3／4／5／6个数字；父母检查期间继续计时。每个夜晚窗口逐渐缩短，比如普通起步七晚从3.60秒降到3.40秒，最后一晚使用困难档3数字。每题另有0.4秒准备。

## 存档与升级

每5秒有效游戏时间、关键变化和中断事件尝试自动保存。存档包含课表、晨检、订正／扣本、罚站、清理进度、同学状态、班长支线、父母阶段、数字排列和剩余时间。失败不会覆盖安全检查点。JSON导入导出用于备份迁移。

升级前先在 v3.3 导出 JSON，再在 v3.4 导入。保留正在进行的课程、棋局、旧成就、已结算日期；不强行倒退补晨检。下一次符合条件的课间／新一天接入新系统。已有夜间记录保留当晚旧反应预算，但隐藏改为对应的多步题；下一晚采用新曲线。迁移中途的周目以当前日作为增压起点，已过日期不补发新版周成就。体验完整新增内容，建议新开一周。

本地存档不是云同步。浏览器清理、无痕会话、文件搬家或崩溃都可能影响恢复；进度重要时请另存一份JSON。离线时间不用于补写、睡觉、罚站、父母检查或奖励结算。

- `逐项验收.md`：本次需求逐项映射到入口与代码。
- `成就说明.md`：124项实际数据清单，含隐藏条件。
- `结局攻略_含剧透.md`：32条实际结局，包含六个新增条件。
- `测试说明.txt`、`tests/`：实际测试方法、日志和局限。

`index.html`前部为DOM/CSS，主体脚本包含原引擎、国际象棋、存档与课程逻辑；新增数据在 `V34_ENDINGS` / `V34_ACHIEVEMENTS`，新增状态在 `makeV34()`，联动逻辑在标有“v3.4 — serializable school-life expansion”的段落。没有外部脚本载入。测试接口仅在显式 `?test=1` 时开放，普通启动不暴露调试对象。

## 测试边界

已通过的测试与数量以 `测试说明.txt` 和JSON结果为准。自动代理读取答案和危险状态，用于发现流程错误，不能代表真人平衡已经校准。触屏采用浏览器模拟，不是手机真机。Safari、Firefox未实测。真实关闭浏览器重开的磁盘测试被当前环境策略拦截，不记为通过。
